# 内置视频生成

## 工作流来源（2026-10-26 更新）

图片和视频默认读取所配置 ComfyUI 左侧已保存的 workflows 目录。Agent 先 inspect，再选择返回的 saved:<文件路径>.json；多个适用工作流由 Agent 根据用户需求和结构化参数选择。提交时重新读取服务器保存版本，不再使用内置导出副本。未保存的浏览器编辑不包含在内。原画布通过 extra_data.extra_pnginfo.workflow 随任务提交，任务回执记录来源路径和源文件内容哈希。只修改请求相关提示词、种子、参考图、输出前缀及明确指定的受支持参数，不覆盖服务器原文件。

只有完整读取目录后，找不到当前模式适用且依赖齐全的工作流，宿主才返回 creation_allowed=true。目录读取失败、解析不支持、排队、超时和运行报错均不放行创建。提交 fallback_workflow 时重新核验。支持 API 格式及带明确控件值的保存格式、子图、基础重路由；自定义前端序列化、复用子图实例或旁路等未支持结构会明确报错，请在 ComfyUI 中导出 API 格式并保存，或修复现有工作流。已安装节点/模型不代表模型组合一定正确，运行错误保留原回执。

格式处理参考 [ComfyUI 官方 API 格式](https://github.com/Comfy-Org/docs/blob/main/development/api-development/workflow-api-format.mdx)和官方前端 graphToPrompt 的职责。官方前端为 GPL-3.0 且依赖完整浏览器运行时，因此未复制或引入其实现；本适配器只转换已保存数据并明确限制支持范围。

完成后返回本地 MP4 和外部播放链接。聊天中的媒体卡片可直接在当前窗口右侧播放本地视频，不依赖 ComfyUI 持续在线；外部播放链接则要求服务在线。旧回执仍可查询补齐外部链接，无需重新生成。

在“设置 → 模型与运行 → 图片与视频 · ComfyUI”保存地址，然后直接让 Agent 生成视频。Agent 通过工具发现加载 `generate_video`，与图片工具共用服务地址及现有会话权限。

图片和视频使用相同的授权界面，提供“拒绝”“仅此次允许”和“本会话允许此工具”。会话授权仅作用于当前对话中的对应工具和服务地址；图片与视频分别授权。选择后，后续生成、查询和取消同一服务的任务可复用授权。重启程序、移除工具、替换实现或更换服务地址后重新确认；显式禁止规则仍优先，不写入全局允许设置。

文字生视频示例：“生成一段 5 秒视频，小熊猫坐在森林溪流边向镜头挥手，640×384，带流水和鸟鸣。”图片生视频示例：“以工作区 reference.png 为首帧，生成 5 秒挥手动画，保持角色一致。”图生视频目前接受工作区内 PNG，按输入图比例设置宽高以避免拉伸。

`generate` 的 mode 为 text_to_video、image_to_video 或 reference_to_video，后两者分别要求 image_path 或 reference_images。尺寸、时长、帧率默认保留所选服务器工作流设置；显式指定尺寸需为 32 的倍数且最多 1344×768，时长为有限正数（支持小数），且需工作流暴露可识别的秒数参数。请求与完成 MP4 均不设固定秒数上限。Agent 必须保留用户指定时长，实际帧数对齐与帧率沿用原工作流。实际节点验证、模型能力、显存、磁盘与既有 128 MiB 下载预算仍适用。参数绑定或服务器执行失败须明确报告，不自动缩短或替换工作流。

工具使用服务已有的 MiniMax H3 FL2VA int8、Qwen3-VL 32B MiniMax int8、视频 fp16 VAE 和音频 fp32 VAE，以及原生采样、解码和 SaveVideo 节点。使用 20 步基础采样，无需额外 LoRA；不会自动安装模型或节点。替换服务地址时需要匹配这些模型与节点。

提交仅一次，返回 job_id 后用 status 查询，wait_seconds 最大 30；网络请求超时 300 秒。只在服务完成、MP4 结构及视频轨元数据通过检查并保存到 `generated-videos/<job_id>/1.mp4` 后报告 completed。回执按会话持久化，修改服务地址后旧任务继续查询原服务；提交结果未知时不自动重发。cancel 仅取消指定任务，不发送全局 interrupt。暂停 Agent 等待并不等于取消 GPU 任务。

模型和节点沿用服务器保存的工作流。复用现有 Harness 工具调用与会话权限，不下载模型或安装节点。

## 在聊天和右侧查看媒体

生成工具返回已完成的本地产物后，聊天中显示图片或视频缩略卡片。点击“在右侧查看”即可在当前窗口预览图片，或播放、暂停和拖动视频进度；无需复制路径到外部播放器。历史回复中用链接、行内代码或独立代码块表示的本地媒体路径也会在确认文件存在且属于当前会话工作区后显示卡片。

预览读取本地文件，已保存的视频不依赖 ComfyUI 在线。图片支持 PNG、JPEG、GIF、WebP（32 MiB 内）；视频支持 MP4、WebM、MOV 容器（128 MiB 内），能否解码还取决于 Electron 支持的编码。生成过程中仍展示工具任务状态，完整视频在实际生成完成并保存后提供预览。文件缺失、超过限制或编码不受支持时显示错误，不修改文件。

实现复用会话工作区检查和右侧文件面板，并采用 [Electron 自定义流式协议](https://www.electronjs.org/docs/latest/api/protocol/)；不开放任意磁盘路径或执行媒体内容。
## 生成过程与宠物入口

Agent 查询回执包含按任务隔离的临时 `progress`（阶段、节点、步数、总步数、连接状态与观察时间），终态清空。采样百分比只描述当前阶段，不代表整体完成度。右侧后台查询和 Agent 查询共用每次请求 300 秒的下载超时，并合并同一任务的并发刷新。提交结果不确定时，在提交结束后重新查询原任务，不重新生成；确认排队、运行或完成后清除过期的提交错误。下载失败保持未完成状态，可针对原输出恢复下载，无需再次生成。

图片和视频生成任务提交后，右侧自动打开“生成预览”，共用本地点阵动画，显示当前阶段、阶段步数和等待时间，不显示中间预览帧。阶段百分比来自服务进度，并非整个任务的总体进度；没有步数时显示“请稍候”。断线后重连，不重复提交；失败或取消后停止动画。完成并保存后，同一卡片自动切换为图片或可播放视频。遵循系统的减少动画设置。

新任务统一提交 `extra_data.preview_method: none`，关闭 ComfyUI 的标准中间预览生成，仍保留 WebSocket 文本进度及状态查询。旧任务或自定义节点发来的二进制预览帧直接丢弃，不编码、不缓存、不传给前端。已提交任务的服务端设置不会追溯修改；最终产物需要的解码与保存节点仍正常执行。该设置依据 [ComfyUI 的预览实现](https://github.com/Comfy-Org/ComfyUI/blob/v0.37.0/latent_preview.py)。

自定义宠物只准备新任务模板，用户发送后才创建会话。宠物卡片描述最多显示三行，悬停可看完整内容，启用按钮底部对齐。

实时数据沿用 [ComfyUI 官方 WebSocket 协议](https://docs.comfy.org/development/comfyui-server/comms_messages)，复用现有依赖，不复制第三方实现。
