# 訊息佇列與立即切換

執行期間的一般傳送會依序排隊。立即切換選取單筆訊息，全部立即傳送選取點擊時的所有待發送訊息。先保存選擇，再取消目前執行及子任務，等待結束後在同一對話開始下一輪；已完成的外部操作不會撤銷。

待發送項目可編輯、刪除、排序及清空。切換或交付中的項目會凍結；儲存失敗保留編輯內容。批次保留個別訊息身份、順序及附件，後來加入的訊息不混入已選批次。

停止及重新啟動保留草稿，須明確傳送才繼續。不明交付先核對原生記錄，不自動重播；重試沿用命令 ID。舊版瀏覽器佇列在後台接收成功後才完成遷移。

Harness 仍掌管執行與工具權限。交付帳本僅管理接入前的訊息；原生消費回執才代表已消費。無法保證遠端模型伺服器立即停止計算，也不會撤銷已完成的工具操作。

編輯前先暫停佇列，防止上一輪結束時送出舊文字；儲存或取消編輯後，點擊傳送草稿繼續。

自動交付寫入期間若直接傳送搶先占用會話，佇列恢復為待傳送並等待該輪結束；不會因此暫停或標記為傳送結果不明。已選批次保留順序，不取消選取時尚未觀察到的新執行。

排隊提交先儲存完整的本機待確認紀錄，再立即清空輸入框。確認到達不會清除後續輸入；本機儲存失敗則保留原文。確認期間可繼續編輯新草稿，但等待上一條確認後才能再次提交。後端拒絕或回執遺失時保留原訊息，可重新整理或重試確認。
