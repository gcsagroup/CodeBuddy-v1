# 對話拖放

執行中的對話保留藍色轉圈。宿主的 `sidebarPlacement`（tasks/project）保存側邊欄歸屬，與 cwd 分開。舊資料沿用原有分組。拖回任務保留目錄與檔案；拖入專案沿用既有目錄切換並保留歷史、重綁工具和刷新快取。相同目錄只改歸屬，執行中跨目錄移動須先由使用者停止。不自動取消、延後或搬移檔案。唯讀、封存和主對話不可移動；CodePro 拖放切換會重綁目錄租約；智慧體限制保留。

`_goose/unstable/session/navigation/move` 接收 sessionId、destination，專案另需絕對 workingDir。Compat 唯一寫入，ACP 與桌面消費；舊客戶端忽略可選欄位。

## 空專案與移除

側邊欄專案使用現有桌面本機儲存範圍（sidebarProjects.v1），移走最後一條對話仍保留空專案。右鍵「移除專案」只隱藏專案，對話在任務列表保留，目錄、檔案與記錄不變；重新選擇目錄可恢復。刷新保留移除狀態。拖放成功先刷新導航，再載入會話；實際目錄切換仍等待後端完成。

拖放目標涵蓋各專案完整分組（含對話與底部留白），任務區延伸至側邊欄底部，無須對準標題。有效區域會高亮，離開、取消或放開後清除。「移除專案」使用 FolderMinus 圖示。
