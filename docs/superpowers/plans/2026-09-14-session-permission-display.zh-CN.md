# 会话模式与权限说明

日期：2026-09-14。[繁体中文](2026-09-14-session-permission-display.md)为默认文档，另有[English](2026-09-14-session-permission-display.en.md)。

## 问题与修正

“自主”原本承诺可自由修改所有文件，“手动”则声称所有工具都要确认，均未准确反映现有规则。修正文案：自主在当前权限内自动执行，受限制或范围外的操作可能需要确认；手动会对尚未由权限规则或只读策略允许的操作询问。本次不修改后端审批决策、拒绝规则或授权复用。

默认模式只用于新会话。`new_session.rs` 创建时读取默认值，`load_session.rs` 和 `execution/manager.rs` 恢复持久化模式。`preferences/save` 不会更新已有会话。英文设置说明原本已正确，但原生验收发现其他语言仍沿用旧译文，本次同步 16 种语言的标题和说明。

全新配置的真实 ACP 响应用 `value: null, isMutable: true` 表示尚未设置。前端原本只处理空列表，导致四个模式选项被禁用。新增回归测试确认修复前失败；现在仅此可编辑空值采用与后端相同的默认自主模式，不自动写入配置。托管值仍禁用，未知值取消选中并显示“未同步”。用户选择后，仍通过已有 revision 校验流程保存。

前端原本丢弃标准 ACP 响应的 `modes.currentModeId`。现在新建与加载均透传至 `Session.goose_mode`，并按通知中的会话 ID 处理 `current_mode_update`。取消后仍接收模式状态通知；已有晚到内容封锁不变。缺失或未知模式显示“未同步”，不用全局默认值代替。

对话输入区上方显示当前模式，可展开查看目录说明。内容使用实际会话绑定：已绑定项目仍受工具规则约束；根目录不是项目写入授权；未绑定表示尚无项目写入授权。普通工作目录仅表示执行位置，不代表所有操作获准。已有确认组件的原因、来源和作用域展示直接沿用。
