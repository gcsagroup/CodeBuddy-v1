對話中獨立成段的本機文件連結顯示為卡片，包含類型圖示、名稱、格式及「開啟方式」。點擊名稱在右側開啟；內文連結、行號引用和既有媒體卡片維持原樣。卡片不是檔案已產生的證據，無法開啟時顯示具體提示。

沿用現有 Excel `.xlsx`、PDF、Word `.docx`、PowerPoint `.pptx` 預覽器。Markdown `.md`、`.mdx`、`.markdown` 顯示排版內容，行號引用保留原始碼定位；CSV/TXT/JSON 顯示文字。舊版 Office 二進位格式不保證內嵌預覽，可使用系統應用程式。缺少字型時提示版式差異。匯入的唯讀歷史保留原有工作區存取限制。
