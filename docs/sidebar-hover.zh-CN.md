# 侧栏会话悬停

会话行与滚动区域右侧保留 4px 间距，移除叠加的右侧外边距。置顶和归档按钮只在悬停或键盘焦点进入行内时占用空间，平时将宽度留给标题。

长标题在鼠标进入整行时立即匀速滚动，去掉原有 600ms 延迟及关键帧起始停顿。移出后复位；系统开启“减少动态效果”时不滚动，完整名称仍可从信息卡读取。

信息卡锚定整行右侧，避免标题因操作按钮出现而变窄后，卡片覆盖操作按钮。卡片展示完整名称、最近更新时间（相对时间及准确日期时间）、工作区别名与完整路径。每次打开刷新相对时间，不为每个会话长期运行计时器。缺失元数据明确显示未知或未关联，不推断工作区。超长内容换行，窄窗口内避让边缘；Esc 可关闭。

更新时间优先使用 `updatedAt`，缺失或无效时回退到 `lastMessageAt`、`createdAt`。复用已有会话元数据和 Tooltip，不改变后端协议、数据存储或会话删除逻辑。
