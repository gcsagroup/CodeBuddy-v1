# 桌面虚拟宠物

设置 → 虚拟宠物提供小熊猫、奶油猫和白狐。小熊猫是默认选择；点击卡片先预览，点击“设为桌面宠物”切换形象并显示，也可单独显示或隐藏。已有自定义选择保留，早期 `buddy` 默认项迁移为 `red-panda`。

支持待机、挥手、跳跃、工作、等待输入、受阻、检查完成和观察方向。拖动移动，点击打招呼，双击跳跃。任务提示消费 ACP 的结构化会话状态；点击提示打开对应会话。减少动画可在设置中开启。

完成提醒在对应会话实际显示且窗口获得焦点后才标记已读；点击跳转本身不提前清除提醒。隐藏会话或后台窗口不会误清除提示，下一轮的新完成记录会再次提醒。移除会话时同步撤下该会话的宠物提示。

一个宠物承载可展开的对话列表，优先显示等待用户处理、受阻、未读完成、工作中的会话。每条显示会话标题及真实活动（思考、撰写回复、当前工具、整理上下文等），已有结构化工作阶段时一并显示；完成项带勾选。新会话尚未命名时显示首条请求摘要。点击哪一条就跳转到哪一条，不推算百分比或从回复文字推断完成。

## 素材与创建

完成勾选与侧边栏绿色未读点消费同一份完成记录，实际查看会话后一起清除。Agent 通过 `ask_user_question` 提问时，宠物显示“等待你回复”和问题摘要，点击进入对应问题；仅查看不会代替回答。工作中可点击“暂停”，沿用会话停止操作；“继续跟进”打开原对话，供用户发送后续要求。

“自定义宠物”在当前窗口新建对话，预填形象、名字、颜色、画风、动作和补充要求模板。用户修改后发送，预填本身不会调用模型，也不会新开窗口。

内置素材随应用打包，日常显示不依赖图像服务。三个角色基于用户确认的原创概念图制作，使用 ComfyUI 的 Qwen Image 2.1 图生图工作流生成连续姿势。网页参考只用于风格调研，没有复制第三方成品素材。

“自定义宠物”打开 CodeBuddy 的主 Agent 会话。Agent 先询问未明确的形象、颜色、风格和名字，再调用内置 `create_desktop_pet`：`prepare` 返回素材要求，`assemble` 装配真实图像、校验并注册预览包。新包会自动出现在设置中，也可手动刷新；用户预览并点击“设为桌面宠物”后才启用。

主 Agent 负责整个流程，通过内置 `generate_image` 调用设置中的 ComfyUI，先生成角色参考图，再生成八组动作网格。聊天模型负责理解需求和编写提示词，ComfyUI 负责生成像素，装配工具负责校验与注册。配置、支持的参考图格式和任务查询见[内置图像生成](image-generation.zh-CN.md)。缺少图像服务时应明确说明，而非把静态复制帧当作新动画。

创建会话使用设置页显示的自定义素材目录作为明确工作区，并预填素材要求供用户编辑后发送。若当前会话缺少图像工具，可以提供自己已有的图像服务和可用工作流，再由 Agent 检查实际可调用性；服务地址、凭据或可用模型不会从 Codex 自动继承。

每个自定义包位于设置页展示的目录内，以稳定英文 ID 为文件夹名，仅包含 `pet.json` 和 `sprites.png`。保留 ID：`buddy`、`red-panda`、`cream-cat`、`white-fox`。

`pet.json` 使用版本 1：`schemaVersion: 1`、`image: "sprites.png"`、`columns: 6`、`rows: 8`、`cellWidth: 192`、`cellHeight: 208`、`fps: 6`，另含 `id`、`name`、`description`。PNG 为透明 RGBA，尺寸 1152×1664。行顺序与上述八组动作相同；观察行依次为上、右上、右下、下、左下、左上。每格保留至少 2 像素透明边缘，每个动作至少有 3 个不同的真实姿势。

坏素材会报告错误并保留已验证版本。内置包异常时可回退到其他有效宠物；没有有效素材时不打开空白悬浮窗口。

## 素材装配

`runtime/assets/assemble-pet.py` 只裁切、缩放、排列生成图，并导出预览及检查记录，不绘制角色；原 `ui/desktop/scripts/assemble-pet.py` 保留为同一实现的入口。内置工具只接受会话工作区内的图像，在临时目录校验成功后一次发布完整包，不覆盖已有 ID，也不自动改变选中宠物。像素校验不等于角色一致性或动作语义验收，仍需预览。生成原图、工作流及本地验收文件放在 `target/pet-redesign`，不随应用分发。
