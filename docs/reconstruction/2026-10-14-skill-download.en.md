# Skill download previews and installation

Sources are in `D:\CodeBuddy-v1`; see `source-baseline.json`. No branches, commits or pushes were created. Renderer files remain unchanged. The implementation connects the existing `skills/manage/download-preview` and `skills/manage/apply` interfaces.

`runtime/skill-download.mjs` accepts an explicit public HTTPS `SKILL.md` URL or GitHub `tree/<ref>/<skill-directory>` URL. GitHub references resolve to a commit and root tree before the selected directory is enumerated. Git tree modes reject symlinks and submodules; paths and collisions are checked, and downloaded bytes must match their Git blob hashes. Public access requires no GitHub credentials. A direct file URL imports only that file without guessing companion locations.

Existing `ipaddr.js` 2.5.0 (MIT) validates addresses, and DNS results are pinned to the HTTPS socket. Every redirect rechecks protocol, port, addresses and allowed GitHub hosts. Limits are 64 files, 1 MiB per file, 4 MiB total file content, five redirects, 20 seconds per request and 60 seconds per download. Query parameters are removed from persisted provenance and the displayed source label.

`LibraryService` keeps the reviewed snapshot in a connection-bound, five-minute memory preview and validates UTF-8 and required Agent Skills fields. The original Apply action installs that snapshot without fetching upstream again. Existing filesystem identity, conflict and single-use checks remain active. Complete directories are staged outside Harness discovery and published with one rename before official skill discovery is refreshed. Disconnect and shutdown cancel pending downloads.

The selected directory's LICENSE, references and scripts are retained. Installation does not execute scripts. Declared licenses are preserved without inferring missing permission or fetching license files outside the selected directory. `.codebuddy-source.json` records the commit, original file hashes and installed skill name/document hash, distinguishing frontmatter renamed for the destination directory.

`node --test runtime/tests/skill-download.test.mjs runtime/tests/library.test.mjs`: 19 passed, exit code 0. Coverage includes original SDK DTOs, actual temporary files, controlled local HTTP byte transport, pinned commits/hashes, address/size/time limits, expiration, disconnects, conflicts, provenance/license preservation and no script execution. Tests did not download from real external skill services or modify user skill directories. Desktop button interaction and actual external services remain separate product acceptance gates.

References: [Agent Skills specification](https://agentskills.io/specification), [GitHub Git Trees API](https://docs.github.com/en/rest/git/trees), [GitHub Contents API](https://docs.github.com/en/rest/repos/contents). Git Trees explicitly exposes link and executable modes, whereas Contents can return target contents for certain symlinks. No dependency installation or legacy agent core was introduced.
