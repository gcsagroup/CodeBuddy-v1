## 已合入內容

- 長對話以視窗方式掛載歷史節點，兼顧搜尋、捲動及選區；媒體輪詢與權限檢查減少整段歷史複製，執行中的會話可匯出既有內容。
- 活躍任務可刷新 MCP 與技能能力；新增語義程式碼查詢、版本化文件查詢、媒體檢查與網頁品質檢查入口，保留各能力的配置和依賴要求。
- 調整建立新聊天時的訊息與草稿狀態、工具箱分組、歷史篩選及工作區瀏覽器互動。
- 補齊新聊天多語言提示，清理已移除介面的舊翻譯；同步模型設定介面與上下文壓縮觸發線的瀏覽器測試。

詳見 [Harness](../runtime/harness/README.zh-TW.md)、[瀏覽器控制](browser-control.zh-TW.md)及[安全說明](security.zh-TW.md)。
