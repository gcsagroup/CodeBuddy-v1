# Conversation file card

The completed-turn file card lists only modifications confirmed by tool receipts. Each path appears once; Windows identity comparison is case-insensitive while macOS preserves case.

Recorded changes show added/removed lines and open the saved turn evidence. View changes opens the full turn. Mentioned or read-only files are excluded; turns without recorded edits show no file card. Historical edits keep their saved receipts rather than recalculating from current file contents.

The card initially shows three rows, with an expand action for additional files and a collapsible header. Both desktop platforms share this component. Browser fixtures exercise both path formats, without establishing native macOS installer acceptance.
