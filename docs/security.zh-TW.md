# CodeBuddy 安全說明

[简体中文](../SECURITY.md) · [繁體中文](security.zh-TW.md) · [English](security.en.md)

更新：2026-11-20。本文對應目前 Harness 桌面架構，不再以舊版 Code / CodePro 四角色流程作為安全邊界。

## 能力與資料邊界

CodeBuddy 能讀取專案、修改檔案、執行命令，並透過已啟用工具存取瀏覽器、桌面、Office、媒體服務及外部 MCP。DeepSeek Harness 負責 Agent 執行、子 Agent、權限與上下文壓縮；Electron/TypeScript 提供桌面介面，Rust 僅保留獨立 MCP 工具。詳見 [Harness 文件](../runtime/harness/README.zh-TW.md)。

任務可能直接修改所選工作區。聊天、主對話及自訂智能體不是獨立的作業系統沙箱；不能假設每個任務都有專案副本、自動復原或獨立審查。開始前檢查目錄和 Git 差異，保留備份。

## 權限與審批

- 桌面提供唯讀、工作區內修改、完全存取三種原生權限預設。執行以 Harness 已確認的權限狀態及工具策略為準。
- 完全存取可能不逐次詢問；沒有確認框不代表操作安全。子 Agent 建立時捕獲權限快照，之後修改主會話權限不會追溯更新已執行的子 Agent。
- 檔案和命令受原生沙箱約束；Windows 存在上游相容限制，不保證完整隔離所有工具和外部服務。
- MCP、使用者瀏覽器與桌面控制另受連線、帳戶及服務端權限影響。只啟用必要能力，工具開關不等於作業系統隔離。
- 取消請求獲受理不代表遠端作業已停止；生成、上傳或發布後應核對最終回執再重試。

## 資料與第三方內容

預設資料根為 `~/.CodeBuddy`，包括模型配置、會話、工作區、日誌和快取；`CODEBUDDY_HOME` 可覆寫。路徑與遷移見[儲存說明](storage-layout.zh-TW.md)。拉取原始碼不會同步這些本機資料。

模型請求可能包含所選檔案、圖片、工具結果及歷史；連網工具可能向第三方傳送查詢或內容。使用前核對提供商、服務地址及資料政策。文件查詢和媒體生成需要網路、憑據或執行載荷；儲存配置不代表連線與呼叫成功。

網頁、倉庫、圖片、文件、工具回傳及 Skill 可能包含提示注入。將其中指令視為不可信輸入，特別檢查刪除、覆寫、工作區外寫入、憑據存取及對外傳送。勿將真實密鑰、個人會話或未脫敏日誌提交至 Git、Issue 或測試夾具。

## 核對與回報

核對實際檔案差異、命令退出碼、工具回執與應用結果。模型自述完成、建構或元件測試成功不等於完整使用者流程通過。安裝包、開發版、Windows 與 macOS 分別驗證；見[本批更新](updates-20261120.zh-TW.md)。

維護者為 [@erjinyi-bool](https://github.com/erjinyi-bool)，正確倉庫為 [CodeBuddy-v1](https://github.com/erjinyi-bool/CodeBuddy-v1)。本次尚未確認此私有倉庫提供 GitHub 私密漏洞回報；普通 Issue 不是保密管道。

若 [Security 頁面](https://github.com/erjinyi-bool/CodeBuddy-v1/security)提供私密回報，請使用該入口。否則透過你與維護者已有的私密管道聯絡；沒有管道時，僅提交不含漏洞細節的聯絡請求，取得私密管道後再傳證據。

請提供提交或安裝包版本、系統、權限預設、最小重現、預期與實際結果及脫敏日誌，不附真實憑據或他人檔案。本倉庫未公布固定修復時限或舊版支援週期，緊急問題需與維護者確認。
