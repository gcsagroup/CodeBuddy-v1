# 现代 Web 开发指南 · Modern Web Guidance

开发或审查网页时，先根据具体交互选择一个分类，使用文件读取工具打开对应索引，再读取相关指南。所有路径均相对于本技能的资源目录。指南中形如 `npx ... retrieve "id"` 的交叉引用，在本地索引中查找同名 Markdown 文件即可。根据项目支持的浏览器选择方案，在真实浏览器中验证行为。

開發或審查網頁時，從分類索引選取相關指南，直接讀取本機文件。依專案的目標瀏覽器驗證實際互動。

For web implementation and review, read the relevant category index and then the matching local guide. Resolve guide IDs in upstream CLI examples to the corresponding local Markdown files. Check target browser support and verify the interaction in a browser.
