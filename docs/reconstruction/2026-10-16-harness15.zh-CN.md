# Harness15：官方 Office 技能和公网抓取

源码：`D:\CodeBuddy-v1`，`main`，基线 `01610d03764570282eee439cd2bfb49fcd373e98` 加本地未提交修改。没有新增分支、提交或推送。本批未改 Rust、前端布局及用户数据。

## 实现

- `runtime/harness/profile.mjs` 直接注册官方 `dsh-skill-office`、`dsh-tool-workspace-dependencies`、`dsh-web`、`dsh-web-fetch-http`、`dsh-tool-web`。未配置的搜索服务不暴露为可用搜索工具。
- `runtime/harness/tool-discovery.mjs` 将依赖查询和网页抓取纳入已有按需加载；技能正文仅在调用 `skill` 后提供，未将三份 Office 技能全文常驻注入每轮。
- `runtime/harness/index.mjs` 从官方技能注册表读取最终获胜定义，适配层向现有来源列表及技能管理列表投影只读条目。真实桌面发现工具箱使用后者，已补齐列表和读取接线，测试覆盖禁止更改内置条目。
- `scripts/prepare-harness-office.mjs` 调用原样保存的官方载荷准备器与 smoke；构建期依赖另用锁文件。Python 及 13 个库遵循官方 `lock.json`，归档校验 SHA256，不修改系统 Python。载荷来自官方固定版本，并未升级整套 Harness。
- `scripts/stage-harness-distribution.cjs` 复制载荷；`scripts/verify-harness-stage.mjs` 实际调用包内依赖查询、Python 文档回读、Shell 与搜索。正常打包不联网安装依赖。

官方构建器来源和准备命令见 [Office builder](../../scripts/office-builder/README.md)。许可证随原样源码及运行载荷保留。Python 3.12.14，python-docx 1.2.0、openpyxl 3.1.5、python-pptx 1.0.2；完整清单在官方锁文件。

## 边界

旧 Rust 独立工具仍保留：PDF、缓存、图表、天气和旧文档 API 没有提前删除。公网 `web_fetch` 不等于私网抓取或二进制下载。Office 采用上游技能指导模型调用官方 Python 库，不是将旧 MCP 工具名称直接映射成等价 API。

本批没有重新执行 H14 的长任务、多次压缩、八模块项目，也没有重跑电脑控制、macOS 或完整 Office 视觉版式检查。PPTX 仅自动 round trip，未做本批真实模型桌面验收。不能据本批 Word/Excel 样本推断所有 Office 格式保真。
