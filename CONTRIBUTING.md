# Contributing to CodeBuddy

Use this repository's Issues and pull requests. Describe a reproducible problem, keep changes focused, and follow [AGENTS.md](AGENTS.md) and [README.md](README.md).

Include relevant tests, exact outcomes and unverified workflows. Verify desktop behavior in the running application. Do not commit credentials, personal conversations, local evidence or build artifacts.

Preserve copyright and license notices: [LICENSE](LICENSE) and [third-party notices](documentation/codebuddy/THIRD_PARTY_NOTICE.md).
