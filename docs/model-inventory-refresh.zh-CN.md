# 启动时刷新模型

允许联网后，桌面后台刷新已配置连接的模型列表，最多同时处理三个连接，不阻塞主窗口启动。手动刷新使用同一运行时逻辑。连接失败保留上次成功的列表，空的有效列表才表示当前连接没有可用模型。

界面顶部提示模型从厂商列表中消失、厂商报告的能力变化或连接刷新失败。提示不会更改默认模型、已有会话模型或用户设置；不可用的模型必须由用户手动重新选择。变化提示确认后消除，未确认提示跨启动保留，模型重新出现后取消其下架提示。

能力比较覆盖厂商报告的上下文容量、输出上限、图片输入、思考选项和工具调用能力。默认模型还复用已有能力查询。首次建立基线不报告能力变化，缺失的元信息不等于不支持。厂商不披露的同名模型替换无法可靠识别。

`runtime/model-inventory.mjs` 统一拥有刷新、连接身份校验、基线和提示；`providers[].inventoryState` 是可选状态，旧数据首次成功刷新时建立，无需批量迁移。`runtime/status` 只投影结构化提示，桌面负责翻译和展示；确认请求绑定通知版本，不能消除较新的变化。更换连接或关闭时，在途结果不得覆盖新配置或继续写入。

参考：[VS Code Language Model Chat Provider](https://code.visualstudio.com/api/extension-guides/ai/language-model-chat-provider)。仅参考发现与变更通知的职责划分，没有复制实现或新增依赖。
