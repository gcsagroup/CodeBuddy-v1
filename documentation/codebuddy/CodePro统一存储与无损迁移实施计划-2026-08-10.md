# CodePro Unified Storage and Lossless Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `C:\Users\<用户名>\.CodeBuddy` the single default CodeBuddy data root, migrate every known legacy store without deleting it, and prove existing settings, sessions, runs, memory, plugins, and Electron profile state survive restart.

**Architecture:** A shared typed path contract defines one root and the fixed `local` profile. Rust owns backend path resolution and the versioned data migrator; Electron resolves the same contract before `ready`, coordinates first-run migration, and relaunches once before opening the new persistent session. Migration is single-write, staged, resumable, conflict-stopping, and never deletes legacy data.

**Tech Stack:** Rust 2021, anyhow, serde/serde_json, sqlx SQLite, fs2, sha2, Clap, Electron 41.1.0, TypeScript, Vitest, Playwright, pnpm.

## Global Constraints

- Default root is exactly `%USERPROFILE%\.CodeBuddy`; `CODEBUDDY_HOME` overrides it with an absolute path.
- Path precedence is `CODEBUDDY_HOME` > valid legacy `GOOSE_PATH_ROOT` > default root.
- This plan implements only `profiles\local`; it does not implement login, synchronization, or account UI.
- Provider/model/permission/user-authored content is profile-scoped; app/window/update preferences are device-scoped.
- Tokens stay in Windows Credential Manager where supported; provider formats that require files use profile state with restrictive ACLs and never ordinary config/logs.
- Electron `userData` is device-scoped and `sessionData` is profile-scoped; both are set before `app.ready`.
- Migration copies, verifies, atomically publishes, and leaves all legacy directories untouched.
- Chromium cache, update binaries, `Update.exe`, and `%LOCALAPPDATA%\CodeBuddy\bin` are not migrated.
- Preserve all unrelated and pre-existing worktree changes. Do not create a branch, commit, push, delete user data, or modify GitHub state.
- Every task uses test-first development and records commands/results under `documentation/codebuddy/evidence/CP-STORAGE-01/` instead of creating Git commits.
- Framework decisions follow [Electron app paths](https://www.electronjs.org/docs/latest/api/app) and [Electron session storage](https://www.electronjs.org/docs/latest/api/session).

```rust
pub const CURRENT_STORAGE_LAYOUT_VERSION: u32 = 1;
pub const LOCAL_PROFILE_ID: &str = "local";

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct CodeBuddyPaths {
    home_dir: PathBuf,
    legacy_override_source: Option<PathBuf>,
}

impl CodeBuddyPaths {
    pub fn resolve(
        codebuddy_home: Option<&OsStr>,
        goose_path_root: Option<&OsStr>,
        user_home: &Path,
    ) -> Result<Self> {
        let new_root = validated_absolute(codebuddy_home)?;
        let legacy_root = validated_absolute(goose_path_root)?;
        let home_dir = new_root
            .clone()
            .or_else(|| legacy_root.clone())
            .unwrap_or_else(|| user_home.join(".CodeBuddy"));
        Ok(Self {
            home_dir,
            legacy_override_source: new_root.and(legacy_root),
        })
    }
}
```

```ts
export interface StoragePathInput {
  codeBuddyHome?: string;
  goosePathRoot?: string;
  userHome: string;
  platform: 'win32' | 'posix';
}

export function resolveCodeBuddyPaths(input: StoragePathInput): CodeBuddyPaths {
  const api = input.platform === 'win32' ? path.win32 : path.posix;
  const requested = firstValidAbsolute(api, input.codeBuddyHome, input.goosePathRoot);
  const homeDir = requested ?? api.join(input.userHome, '.CodeBuddy');
  return buildLocalProfilePaths(api.normalize(homeDir));
}
```

```rust
pub async fn execute(&self, plan: &StorageMigrationPlan) -> Result<StorageMigrationReport> {
    self.verify_available_space(plan)?;
```
