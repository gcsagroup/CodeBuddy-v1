# 文件卡片与会话删除

2026-11-10 更新：删除采用持久化受理和后台清理，界面不再等待大快照写入或 MCP 连接释放；详见 [异步删除会话](async-session-delete.zh-CN.md)。

对话中独立成段的本地文档链接显示为文件卡片，包含类型图标、名称、格式和“打开方式”。点击名称在右侧打开；正文中的内联链接、行号引用和已有媒体卡片保留原来的显示。文件不存在或不支持预览时显示具体提示，不能把卡片视为文件已生成的证据。

右侧复用现有预览器：Excel `.xlsx`、PDF、Word `.docx`、PowerPoint `.pptx`；Markdown `.md`、`.mdx`、`.markdown` 渲染正文，带行号的引用保留源码定位；CSV/TXT/JSON 等按文本显示。旧版 Office 二进制格式不承诺内嵌预览，可通过“打开方式”使用系统应用。Office 转换缺少字体时会提示版式可能不同。导入的只读历史仍遵守原有工作区访问限制。

会话右键菜单在“归档会话”下方提供“删除会话”。确认框说明不可在 CodeBuddy 内恢复，并保留工作区文件。取消不删除；请求失败保留确认框和会话。成功后刷新列表，删除当前会话时返回新任务页。运行中的会话由已有后端拒绝删除，需要先停止任务。
