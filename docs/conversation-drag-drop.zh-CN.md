# 对话拖放

运行中的对话保留蓝色转圈。侧边栏归属由宿主会话字段 `sidebarPlacement`（tasks/project）保存，与实际 cwd 分开。旧数据缺省时沿用原有 workspaceOrigin/目录分组。

拖回任务只解除项目分组，保留工作目录和文件；拖入项目复用现有目录切换，保留历史，重绑原生工具并刷新缓存。相同目录仅更新分组；运行中跨目录移动拒绝，先由用户停止再重试。不自动取消或延迟执行，不搬动磁盘文件。只读、归档和主对话不可移动；CodePro 通过拖放入口切换时由工作区服务确认并重绑目录租约；智能体目录限制继续生效。失败保留原归属。

接口为 `_goose/unstable/session/navigation/move`，必需 sessionId 与 destination，项目目标另需绝对 workingDir。Compat 是唯一写入者；ACP 元数据、桌面导航是消费者。回滚时旧客户端忽略可选字段，不改变执行目录。

## 空项目与移除

侧边栏项目目录单独保存在现有桌面本地存储范围内（sidebarProjects.v1），最后一条对话移出后保留空项目。右键“移除项目”只隐藏侧边栏项目，其对话在任务列表继续可见，实际工作目录、文件与聊天记录不变。重新选择目录会恢复显示。移除标记在刷新后保留，普通对话刷新不会自动重新添加。拖放成功后先刷新导航，再重新加载会话，避免导航等待工具/MCP重绑定。实际目录切换仍须等待后端完成。

拖放目标覆盖每个项目的整个分组（含对话行与底部留白），任务区延伸至侧边栏底部；不要求命中标题。拖入有效区域显示高亮，离开、取消或松手后清除。右键“移除项目”使用 FolderMinus 图标。
