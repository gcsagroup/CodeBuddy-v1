## 范围和统一原则

用户已批准按统一设计实施。设计依据为 [对话体验设计](../plans/2026-09-25-codepro-conversation-experience-design.zh-CN.md)，不替换已冻结 R3，不新增任务状态机、Judge 或总结 Agent。

统一原则：正文解释工作；计划帮助理解范围；操作记录提供可核对事实；异常和审批直接可见；结束时交接成果和缺口。自然语言遵循用户明确要求、已知偏好、当前 query，最后才使用界面语言。模型说明不提升为权限、完成或恢复事实。

## 本阶段已实施

- `CodeProToolContent.tsx`：计划直接呈现现有业务清单；写入内容、编辑请求的前后片段、命令及退出状态可直接阅读，不先穿过参数表。明确区分提交内容与真实工作区 diff，未新增撤销或虚构增删行。传输失败保留，计划更新失败不冒充成功。
- `ToolCallWithResponse.tsx`：普通成功操作不重复显示“工具调用已完成”；已知文件动作使用本地化标题；计划独立于普通工具分组；技术参数与审计可展开。保留非文本工具结果及原审批入口。
- `ProgressiveMessageList.tsx`：普通 Change 消息实际使用的请求/回执也参与轻量分组；隐藏消息、回执和思考不产生空白行；计划和公开正文是阅读边界；错误、审批及当前运行操作不折进成功历史。分页不再截断当前操作序列。组标题是实际操作摘要，不冒充业务阶段总结。
- `ToolCallExpandable.tsx`：按稳定身份保存本标签页的展开选择，历史重载可恢复；展开内容限高滚动并按需挂载。尚未证明百条复杂输出的桌面性能。
- `MarkdownContent.tsx`：既有技术详情折叠支持英文标题。
- 16 个语言目录：补齐新增展示文案；不翻译路径、代码及命令。
- `agent.rs`：语言指导明确优先级；未完成报告委托给既有报告模块。
- `codepro_terminal_report.rs` / `tool_task.rs`：仅用已有可信文件变化和验证回执生成部分结果交接，原始 gap 放技术详情，不改判终态、不承诺无效恢复、不展示被拒绝完成草稿。Rust 改动尚未编译验证。

新视图沿用既有工具输出的 audience 限制；不把仅供 Agent 的回执公开。完整的凭据脱敏机制审查仍未完成，不能宣称所有参数和命令均已脱敏。

## 必须保留的问题清单

| 用户问题 | 当前处理与剩余边界 |
|---|---|
| 没有阶段性人话、只剩工具记录 | 不能仅靠前端解决；公开进度与完成提议分离需要下面的有限扩展，尚未实施 |
| 计划看不见 | 已接入现有 todo 内容；计划不是验收证明，尚需桌面观感验收 |
| 内容英文、工具术语多 | 已知操作本地化，模型语言指导已改；动态说明及所有宿主消息尚未全语言贯通 |
| 每条大卡片、空白多 | 普通工具轻量化、空消息不占行；真实窗口尚未验收 |
| 展开命令太长、折叠状态丢失 | 限高滚动、稳定身份保存展开状态；用户上翻时的完整滚动策略仍待验证 |
| 文件详情是参数 JSON | 常见文件操作直接阅读；真实 diff、路径打开与完整产物交接仍需核对现有能力，不伪造 |
| 暂停只给内部 ID | 已增加事实支持的部分结果交接；未知动作错误分类的根因不能靠文案修复 |
| 自主模式仍反复批准、ask_user 抛内部选择 | 属既有 R3 权限/提问链，保留原事实 owner；本阶段未改、未重新验收 |
| 子 Agent 拉不起来、超时帮倒忙 | 属既有 R3 委派/暂停恢复链；本阶段未改、未重新验收，不以“不委派”规避 |
| 假完成、继续失联、重复复核 | 保留既有控制面门槛；展示优化不能豁免这些问题，后续仍需运行证据 |
| 重建后白屏或模型不可用 | 本阶段尚未重建/启动，不使用旧进程证明本轮生效 |

## 公开进度的有限扩展：已按后续指示实施

当前主循环把没有工具调用的正文作为完成候选处理，拒绝的候选被隐藏；现有模型和消息结构不能可靠区分公开进度与最终完成提议。仅重复提示“多说进度”无法闭合链路。

建议增加只负责公开说明的进度入口，复用既有消息持久化和显示。它不能批准动作、修订目标、改变生命周期、注册完成证据或绕过完成门槛。旧会话保持原消息解释，无新进度时使用真实操作状态降级。不得按自然语言关键词识别进度与完成。

提出确认后，用户指示“不需要做多余的测试，直接改到 E2E 为止，构建编译完”。已明确告知将其理解为批准该有限入口，并继续实施：新增 `codepro__publish_progress`，宿主只验证消息格式/长度，原会话请求和回执负责持久化，UI 收到成功回执后按正文展示且形成操作组边界。它不进入交付证据或失败计数。旧会话无需迁移，错误请求保留原失败展示。相关权威地图已记录该有限扩展。

没有继续新增测试；仅完成必要类型检查和构建。此前的测试结果不声称覆盖此后新增进度入口，真实消息模型行为交由本轮 E2E 验收。
