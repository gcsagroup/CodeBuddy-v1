# Ollama Cloud G0/G1 资格验证 v1

这套评测只使用脱敏内容，用来验证某个明确的 Ollama Cloud 模型是否具备研究版所需的基础协议和只读分析能力。阈值必须先固定再执行，失败后如果修改提示词、工具或阈值，必须创建新的版本目录，不能覆盖失败记录。

## G0：协议

- 使用 `prompts/g0.txt` 新建独立会话，连续执行 3 次。
- 每次必须在 120 秒内完成。
- 输出去除首尾空白后，必须能够解析为 JSON，且严格等于 `{"status":"ok","sum":42}`。
- 3/3 通过才记为 G0 `PASS`；任意一次失败即记为 `FAIL`。

## G1：只读仓库

- 只有同一模型的 G0 已通过才执行。
- 将 `fixtures/g1-readonly` 复制到一次性临时目录并初始化 Git。
- 记录执行前的目录 SHA-256 和 `git status --porcelain`。
- 在该目录使用 `prompts/g1.txt` 新建独立会话，连续执行 3 次。
- 每次必须在 180 秒内找到正确文件和行号，并说明加法错误；相同参数的工具调用不得连续超过 2 次。
- 执行后目录哈希必须不变，`git status --porcelain` 必须为空。
- 3/3 通过才记为 G1 `PASS`；有修改、证据错误、超时或循环读取均记为 `FAIL`。

## 结果记录

每次记录资格版本、时间、Provider、完整模型 ID、应用提交、提示词哈希、fixture 哈希、耗时、工具调用摘要、结果和停止原因。严禁记录 API Key、Authorization 头或系统凭据内容。
