# 压缩模型兜底

压缩依次使用三个层级：原生压缩模型、用户指定的可选兜底模型、固定的 Qwen Flash。未指定时跳过中间一级；同一连接和模型只占一个层级。摘要成功后，仍按当前聊天模型的实际请求预算验收，不以兜底模型的大窗口作为成功条件，也不切换聊天模型。

## 职责与边界

- Compat 从现有连接和配置解析明确的来源模型及兜底模型。配置不会创建连接或恢复已删除的旧连接。
- Harness 的既有压缩引擎继续选择范围、保护最近用户输入、保持工具调用/结果配对、验证摘要、提交检查点、刷新日志和处理取消。
- 摘要为空、输出截断、摘要不比原文小、摘要请求无法放入窗口，以及提供商返回的调用、认证、传输、超时或限流失败时，进入下一个配置层级。取消和内部准备调用合同错误不因此换模型；Flash 是最后一级，不轮回重试。
- 某一级生成了有效检查点但还需要继续缩减时，继续使用该模型处理原生分段，不因为分段而提前进入下一级。
- 手动压缩在同一次原生维护锁内最多做 8 轮有效缩减。每轮都用目标模型的原生消息投影和适配器计量，包括系统提示、工具、输出预算和安全余量；不生成探测回答。
- 输出空间沿用原有动态预算与最低输出约束，不强求每次都保留完整 32K 输出。新的用户输入、工具或配置变动仍由下一次正常请求重新检查。
- 目标窗口仍放不下、无法继续缩减、兜底模型也失败或用户取消时，停止并保留原始历史及已经提交的检查点；不会重放已完成工具。

原生已有的独立摘要模型配置仍作为第一级；默认跟随当前模型。兜底连接仅在需要恢复时加载，不为正常聊天额外发现模型或解密凭据。该机制不承诺所有模型离线时还能生成摘要，也不会丢弃超过目标窗口的受保护用户输入来宣告成功。所有层级均失败时保留会话、文件和已完成回执，连接恢复后可明确重试，不自动重做任务。

## 配置

入口为“设置 → 模型与运行时 → 上下文压缩”。复用已有设置菜单、分组模型下拉框、保存按钮与未保存标记。选择“不指定”表示原生失败后直接使用 Flash，不代表关闭最终兜底。读取失败不能覆盖保存值；保存失败保留草稿；被删除的已选模型显示为不可用，不静默改选其他模型。

新全局配置通过既有 `config/upsert` 保存为 `compactionFallbackModel`：

```json
{ "model": { "providerId": "existing-connection", "modelId": "chosen-backup" } }
```

`{ "model": null }` 跳过用户自选一级。默认的最终兜底只使用 `runtime/default-model.json` 指定的 `qwen3.8-flash-next-uncensored`，不再选择 FP4 或 CyberSecurity。使用现有的 `http://192.168.9.120:8001` 连接，旧连接的保存列表尚未加入 Flash 时也可按需解析固定型号；不创建新连接，不恢复失效连接，不改写原保存列表。同名连接不唯一时不随意选择。

旧的高级 `compactionFallbacks` 配置仍保留兼容读取，使用精确的连接与模型标识：

```json
[
  {
    "source": { "providerId": "existing-gemma-connection", "modelId": "gemma-model" },
    "fallback": { "providerId": "existing-qwen-connection", "modelId": "qwen-model" }
  }
]
```

尚未保存新全局设置时，旧数组继续按原来源模型应用，旧空数组也继续表示禁用。设置页会提示该状态；用户明确保存新全局选择后才覆盖其效果，不删除旧值。删除兜底连接不影响普通聊天的原有模型选择；旧会话无需迁移。

## 故障判读

“上下文压缩失败”不是单一原因。应查看原生 `compaction/end` 错误链以及模型诊断中的实际连接、模型、输出额度和结束原因：

| 证据 | 能支持的结论 |
| --- | --- |
| `NO_ADAPTER` / `no adapter registered` | 本地连接不可用，不能据此判断模型摘要能力 |
| `EMPTY_RESPONSE` / `COMPACTION_EMPTY_SUMMARY` | 没有可提交的正文摘要；思考是否耗尽额度须结合实际结束原因 |
| `MAX_TOKENS` / `OUTPUT_TRUNCATED` / `OUTPUT_LENGTH_STOP` / `OUTPUT_LIMIT_REACHED` | 输出触顶或检查点不完整；服务提前以 length 结束、尚未达到声明额度时也不能提交半截摘要 |
| `COMPACTION_NOT_SMALLER` | 摘要未比被替换内容小 |
| `COMPACTION_TARGET_WINDOW_EXCEEDED` | 已有检查点保留，但剩余受保护内容仍无法适配目标窗口 |

仅凭另一台电脑的通用错误截图，不能确定是哪一种，也不能把切换连接的修复当成所有 Qwen 失败的解决办法。
