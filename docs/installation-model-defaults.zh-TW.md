# 工具箱與安裝預設模型

自 1.43.7 起，全新安裝只預置預設選取的 **CodeBuddy LAN**。已移除 Ollama Cloud 發行預設與共享 Key 自動匯入；打包階段明確排除舊的 `runtime/distribution-credentials.json`，即使本機建置目錄仍有該檔也不會分發。既有使用者自行設定的連線與憑據保留，使用者仍可在設定中手動新增提供者並填入自己的憑據。

工具箱「全部」按內建能力、技能、外部 MCP 分組。電腦控制是執行工具；桌面操作指南（computer-use）是模型載入的技能，不會自動開啟電腦控制。本機 Git 管理工作區儲存庫，GitHub 連接遠端儲存庫、議題、提取請求與 CI。

全新安裝的 Windows/macOS 桌面透過同一個 Harness 狀態初始化入口讀取 runtime/default-model.json，預設使用 http://192.168.9.101:8001 的 gemma-4-26B-A4B-it-uncensored-FP8-W8A16，設定上下文為服務在 2026-10-22 回傳的 65,536 tokens。安裝啟動不主動傳送使用者內容，也不要求模型伺服器在線。

主模型與輔助圖像辨識預設選擇同一服務。2026-10-23 使用隔離的紅藍圖片實測，模型正確辨識了左右顏色；發行預設因此啟用圖像輸入。此結果只證明本次圖片請求成功，不代表電腦控制或其他工具已驗收。

這是區域網路預設，其他網路可能無法連線。使用者可在設定 → 模型與執行中修改服務位址、新增提供者，並分別切換主模型、圖像辨識模型與圖像能力設定。已有 state.json 不注入或覆寫預設；使用者刪除預設後，重新啟動不會再新增。不變更系統網路授權。
