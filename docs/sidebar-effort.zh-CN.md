# 侧栏与思考强度交互

工作区显示在任务上方。对话悬停提供置顶和归档；右键保留完整操作菜单。置顶对话留在原文件夹／任务分组内，后置顶的排在前面。取消置顶后按原活动顺序排列。

文件夹悬停提供更多菜单和新建对话。更多菜单包含置顶、重命名、归档其中的对话。归档会先列举所有匹配会话并确认数量，不删除文件。部分归档失败时可重试剩余记录。

聊天思考强度调整暂存在当前应用内，发送下一条任务时才保存到原连接／模型设置并应用。不会因拖动或键盘调整发送配置请求，也不会改变已运行任务。退出应用前未发送的调整不会保存；自动续跑不消费新调整。设置保存失败时任务不会开始，草稿保留供重试。

模型列表的搜索框旁提供刷新按钮；刷新期间防止重复点击，刷新失败保留之前的列表和当前模型，可再次点击重试。

文件夹名称左键用于展开／收起对话；左键点击旁边「更多」中的「打开文件夹」，会在系统文件管理器中打开该项目的真实路径，与对话菜单使用相同入口。打开失败显示错误，可再次重试。
