# 生成媒体画廊

同一轮回复中的已完成图片和视频合并到一个画廊：一块主预览、横向缩略图、左右切换按钮和当前位置。单个结果保持原有直接展示。生成中的任务以紧凑进度显示；失败原因仍在各自工具记录内，不与其他任务混为一个结果。不同对话轮次保持分开。

点击缩略图或左右按钮切换，触控板和触屏可横向滚动缩略图。不自动轮播。现有放大、另存为、外部打开和侧栏查看继续作用于当前选中媒体。新结果到达时保留当前选择。显式媒体回执中的结果不再被原来的 8 项/12 项显示上限截断；从普通文本推测文件路径仍保留数量限制。

视频画廊仅挂载当前播放器，其余用编号和视频标识表示，不为每个缩略图创建播放器。切换时停止旧播放器，不自动播放新视频；当前视频只预加载元数据。图片缩略图延迟加载，主预览高度受限，避免结果数量增加导致聊天持续拉长。

本改动只处理展示，沿用真实工具回执和已有文件校验，不改变生成任务、权限、持久化或 Harness 执行。参考 [W3C Carousel Tutorial](https://www.w3.org/WAI/tutorials/carousels/) 的用户控制、可命名按钮和当前位置提示；使用现有 React、CSS 和媒体组件，无新增依赖或第三方实现拷贝。美术质量与视频生成速度不由排版改动保证。
