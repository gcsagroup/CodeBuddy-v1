# 长期目标与计划命令

在新任务或已有对话的输入框中输入 `/`，即可查看功能。支持搜索、上下键选择、回车确认、Esc 关闭，也可直接点击。Windows 与 macOS 共用此界面，不再显示常驻目标表单。

- `/goal 目标和验收标准`：创建目标并开始执行，使用 Harness 原生自动续跑上限（当前锁定版本默认 256 轮），会消耗模型额度。
- `/goal pause`：暂停目标和当前执行；执行中也可使用。
- `/goal resume`：从保存的进度继续。应用重启后需要明确继续。
- `/goal status`：按需显示目标、真实状态、已用轮数和阻塞原因。
- `/plan 任务`：启用计划模式并研究任务，提交方案供用户审阅后再实施。
- `/plan`：在已有对话切换到计划模式；新任务中提示补充任务内容。
- `/plan off`：退出计划模式。不会改变会话批准方式。
- `/compact`：使用已有上下文压缩入口。

目标状态、轮次和持久化仍由 Harness GoalService 管理；计划状态由锁定版本的原生 PlanModeController 管理。计划指导与工具批准策略分别生效。前端只传递显式命令，不解析普通文字来推断授权或任务阶段。目标标记完成后，仍应检查测试和实际结果。

菜单按添加、指令、技能和常用任务分组。主菜单提供文件、目标、计划、压缩、权限、模型、导出；技能与常用任务来自实际配置，不显示尚未实现的功能。暂停、继续与清除放在目标状态条，退出计划模式使用蓝色计划标记。

选择目标或计划后，输入框显示蓝色前缀与提示；点击前缀或在空输入框按退格可退出。已有未完成目标时，选择目标或点击状态条会打开右侧“编辑目标”标签页。大文本编辑区支持撤销、保存，关闭未保存内容时会确认；保存不会启动或恢复目标。保存冲突时保留草稿，可读取最新目标再处理。普通消息草稿保持不变。

文件与权限、模型入口复用现有功能；导出会将当前对话下载为 JSON。已有显式 `/goal edit 新目标` 与 `/goal clear` 命令继续可用；清除目标保留对话和项目文件。

斜杠菜单还按技能、MCP 服务、内置工具分组展示工具箱清单，支持名称与描述搜索。禁用条目会标注状态；点击后进入对应详情，浏览不会自动启用或调用工具。项目技能按当前对话目录读取，各类列表独立加载，部分失败会提示重试。

计划审阅使用独立卡片展示 Markdown 正文，下方以编号选项提供“批准并实施”和“继续规划”，第一项标注“推荐”，选择后点击“发送”。底部常驻输入框，可直接填写自己的想法；带修改意见的回复始终保留计划模式。审批按钮仅发送 Harness 原生选项，计划与执行状态仍由 Harness 决定。
