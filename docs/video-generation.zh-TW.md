# 內建影片生成

完成後傳回本機 MP4 與外部播放連結。聊天中的媒體卡片可直接在目前視窗右側播放本機影片，不依賴 ComfyUI 持續在線；外部播放連結則需要服務在線。舊回執仍可查詢補齊外部連結，不必重新生成。

於「設定 → 模型與執行 → 圖片與影片 · ComfyUI」儲存服務位址。Agent 可透過工具探索載入 generate_video，沿用圖片工具的位址與會話權限。

文生影片：「生成 5 秒小熊貓在溪流邊揮手的影片，640×384，帶流水和鳥鳴。」圖生影片：「以工作區 reference.png 為首幀生成 5 秒動畫。」目前圖生影片接受工作區 PNG，寬高請配合圖片比例。

generate 的 mode 為 text_to_video 或 image_to_video，後者需要 image_path。預設 640×640、5 秒、24 fps；寬高為 32 倍數，總像素上限 1344×768，時長 5–15 秒按 17k+5 幀向上取整，5 秒通常得到約 5.17 秒。

使用已安裝 MiniMax H3 FL2VA int8、Qwen3-VL 32B MiniMax int8、影片 fp16 VAE、音訊 fp32 VAE 與原生節點，20 步基礎採樣，不自動下載模型或安裝節點。更換服務需具備相同模型與節點。

提交一次後以相同 job_id 查詢 status，每次等待最多 30 秒，HTTP 上限 300 秒。伺服器完成且下載的 MP4 結構、影片軌元資料通過檢查並寫入 generated-videos/<job_id>/1.mp4 後才回報 completed。回執依會話保存，舊任務保留原服務位址；未知提交結果不自動重送。cancel 僅針對該任務；暫停 Agent 等待與取消 GPU 任務各自獨立。

依據[官方 H3 原生工作流程](https://docs.comfy.org/tutorials/video/minimax/minimax-h3-native)與服務節點介面，自行組裝 API 圖。官方 Harness 提問模組為 MIT；模型授權依各模型條款。模型清單或佇列成功不等於生成驗收。

## 在聊天和右側查看媒體

生成工具回傳已完成的本機產物後，聊天中顯示圖片或影片縮圖卡片。點擊「在右側查看」即可在目前視窗預覽圖片，或播放、暫停和拖動影片進度；無須複製路徑到外部播放器。歷史回覆中的連結、行內程式碼或獨立程式碼區塊所列的本機媒體路徑，也會在確認檔案存在且屬於目前對話工作區後顯示卡片。

預覽讀取本機檔案，已儲存的影片不依賴 ComfyUI 在線。圖片支援 PNG、JPEG、GIF、WebP（32 MiB 內）；影片支援 MP4、WebM、MOV 容器（128 MiB 內），解碼仍取決於 Electron 支援的編碼。生成中維持工具任務狀態，完整影片於實際完成並儲存後提供預覽。檔案遺失、超過限制或編碼不受支援時顯示錯誤，不修改檔案。

實作沿用對話工作區檢查和右側檔案面板，並採用 [Electron 自訂串流協定](https://www.electronjs.org/docs/latest/api/protocol/)；不開放任意磁碟路徑或執行媒體內容。
## 生成過程與寵物入口

生成任務提交後，右側自動開啟「生成預覽」，顯示目前階段、階段步數及服務實際傳回的最新預覽畫面。階段百分比並非整段影片的總進度。尚無畫面時顯示等待；斷線後重連，不重複提交。完成儲存後，同一卡片自動切換為圖片或可播放影片。

自訂寵物僅準備新任務範本，使用者傳送後才建立對話。卡片描述最多三行，停留可看完整內容，啟用按鈕底部對齊。

即時資料沿用 [ComfyUI 官方 WebSocket 協定](https://docs.comfy.org/development/comfyui-server/comms_messages)，沿用既有依賴，不複製第三方實作。
