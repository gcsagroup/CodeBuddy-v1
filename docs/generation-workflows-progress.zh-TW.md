# 生成等待回饋與固定工作流程（2026-10-23）

本批基於 main，開始版本 f6d5317，另一項任務提交後為 09b0219。本批尚未提交，保留其他任務修改。

## 原因

提供的寵物對話兩次等待模型 HTTP 回應標頭分別耗時 206286 ms、122499 ms；服務端排隊、網路與預填充的各自耗時尚無證據。另兩個對話的請求耗時 1377089 ms、714797 ms，期間持續收到 22026、16423 個推理字元，回應標頭僅花 19 ms、56 ms。因此等待回應與串流生成須分開顯示。匯出訊息時間重複，本次採用原生紀錄判讀。

角色首圖未傳入真實原圖，後續動畫沿用此首稿；搜尋成功不代表外觀準確。右側預覽原先也會等待遠端查詢或下載完成才顯示既有工作。

## 修改

顯示明確的等待模型狀態，20 秒沒有新活動時顯示說明，沿用現有停止按鈕。右側先顯示已儲存的工作，再背景去重更新，呈現節點階段、佇列位置、經過時間及預覽；不虛構整體百分比。

六個固定範本：qwen_image、qwen_edit、minimax_text、minimax_text_detail、minimax_image、minimax_reference。預設優先重用既有範本。經使用者授權，只有目前模式的已登記範本都缺少節點或模型時，才允許提交 fallback_workflow；宿主於提交前重新檢查 /object_info。未指定尺寸與時長時保留範本預設；指定尺寸須符合支援比例及至少 0.1 MP。只有一張參考圖時，兩個參考槽使用同一張真實圖片，保留連線並避免引用範例檔。

唯一經使用者核准的修訂：QI2.1_i2i 的 459:453 編碼器換成 qwen3vl_8b_int8_convrot.safetensors。原本 MiniMax 32B 編碼器造成預期 4096、實際 5120 維錯誤；其他節點、連線及參數不變，D:/ 原檔保留。修訂後 SHA256：6e05bc8a3e62376e9ad80603f7f5eba8f25e0e1f73795da500ac194a4dcc59be。

寵物 prepare 指引要求已知角色先查看真實參考圖、展示首稿並取得相似度確認，再製作動畫。這是 Agent 流程指引，未新增強制審批狀態機；最終相似度仍須使用者確認。

## 沒有可用工作流程時建立（本輪補充）

圖片與影片工具新增 operation=inspect，回傳模式範本、缺少的依賴、creation_allowed、分頁節點名稱及實際輸入/輸出定義。Agent 根據已安裝節點與模型組合 API 圖；宿主檢查大小、連線、循環、輸出、參考圖與提示詞/明確參數綁定，再由 ComfyUI /prompt 執行最終校驗。斷線、排隊及執行失敗不開放替換；不自動安裝下載。沿用任務回執、查詢、取消及產物保存。

範圍：目錄是 CodeBuddy 已登記的六份匯出；尚未自動掃描 ComfyUI 前端儲存的工作流程，新建圖記錄於任務回執，尚不自動加入範本目錄。

本輪六個相關 Node 24 測試檔共 27 項通過，退出碼 0；新增測試包含 Harness 與隔離 HTTP 服務、影片提交及服務拒絕。真實服務唯讀檢查取得 960 類節點、六份範本依賴可用，五種模式皆不開放替換。本輪新分支尚未進行桌面模型選擇及 GPU 生成 E2E；已啟動的桌面尚未重新啟動載入本輪後端修改。
