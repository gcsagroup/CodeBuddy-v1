# Source update: 2026-11-20

[简体中文](updates-20261120.zh-CN.md) · [繁體中文](updates-20261120.zh-TW.md) · [English](updates-20261120.en.md)

The source baseline is [25cbb9815](https://github.com/erjinyi-bool/CodeBuddy-v1/commit/25cbb9815f304f35583bf3e7fa716e299cba060c), merged into main. The desktop manifest remains at 1.43.18. This is a source update, not an installer or release announcement.

## Included changes

- Windowed long-chat history with search, scrolling and selection support; reduced full-history copying during media polling and permission checks; export of existing content during active sessions.
- Live MCP and skill refresh, plus semantic code queries, versioned documentation queries, media inspection and web-quality checks, subject to their configuration and dependency requirements.
- Updated pending-message and draft behavior during chat creation, grouped tools, history filtering and workspace-browser interaction.
- Completed new-chat translations, removed obsolete UI translation keys, and updated browser fixtures for model settings and the context-compaction threshold.

See the [Harness documentation](../runtime/harness/README.en.md), [browser guide](browser-control.en.md) and [security policy](security.en.md).
