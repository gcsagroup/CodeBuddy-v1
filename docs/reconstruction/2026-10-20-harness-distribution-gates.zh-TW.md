# Harness 分發門禁與語言目錄修復

[简体中文](2026-10-20-harness-distribution-gates.zh-CN.md) · [English](2026-10-20-harness-distribution-gates.en.md)

以既有 `main`、`6eb8f7e` 為基線，修正上一批 10 項過時測試，未恢復舊 Rust Agent、Provider、Coordinator、TLS 服務或 PowerShell 建置入口，未變更產品執行機制。

測試現在覆蓋 Harness IPC loopback 就緒與私密連線金鑰、分發遙測開關、空白模型設定、模型按鈕可存取名稱、建置驗證順序、精確 x64 產物與 manifest 比對、Squirrel 歸檔驗證及既有安裝器保護、建置不自動安裝、Forge 拒絕未驗證 stage，以及服務冪等關閉與逾時終止。

完整分發門禁另發現一個引用已移除 Coordinator 的測試，改為執行現有 `runtime/tests/harness-authority-acp.test.mjs`，驗證原生完成、真實失敗及驗證證據邊界。核心判定仍由原本模組負責。新的測試輔助檔只使用臨時目錄並攔截外部程序，不安裝或修改使用者資料。

13 種非中文語言目錄各補齊 97 個缺失鍵、移除 23 個廢棄鍵，保留 2771 條既有描述及譯文。新增項目使用英文源文，延續 `defaultMessage` 回退，不聲稱已完成這些文案的本地化翻譯。英文、簡體及繁體目錄本批無須修改；既有鍵與 ICU 校驗未放寬。

現有 Node 24.21.0 下，完整分發門禁 51 項通過（其中一項執行現有 13 項 Harness 合同回歸）；入口與 macOS 打包腳本 42 項通過；語言及模型選擇元件 29 項通過。英文提取與 15 個翻譯目錄驗證通過，每份 2868 條；16 個語言目錄編譯通過。上述命令退出 0，完整命令見簡體版。

這是測試與語言資料維護，未改產品邏輯，不代表真實模型、桌面或安裝包驗收；未安裝依賴、製作安裝包或修改 Rust。本機證據在 `.preview-evidence/distribution-gates-20261020/`，不提交。更新後沿用 README 的 Harness 建置入口。最終提交與推送狀態以交付訊息及遠端 Git 為準。

驗證期間另一任務開始修改媒體預覽及英文、中文目錄，本批不納入這些未提交內容。提交前以原有語言校驗腳本讀取 Git 暫存版本，15 個翻譯目錄、2868 個鍵通過；此結果只涵蓋本批提交，不代表其他開發中的工作區改動已驗收。
