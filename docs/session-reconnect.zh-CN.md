# 界面重连与任务执行

刷新界面或 ACP WebSocket 断开后，已接纳的任务继续由同一个 Harness 执行。重新连接时，桌面加载原会话，回放日志并接续实时消息，不重复发送用户请求或生成图片。

`runtime/server.mjs` 负责连接与待答 RPC；`runtime/session-connection.mjs` 只负责活动会话的客户端投递。`runtime/compat.mjs` 在完成 session/load 后绑定客户端，并提供真实的 activeRunId。前端使用既有连接恢复通知加载当前会话，清除已结束请求的过期运行显示。

断线期间需要用户选择时，权限、问题和配方参数等待恢复，在原生请求、权限作用域和截止时间内重新呈现。浏览器及桌面命令不自动重放。主动停止仍取消任务；服务关闭仍执行原生关闭流程。后端进程崩溃、系统重启后的自动续跑不属于此保证。无需迁移既有会话。

工具错误保留可读原因；结构化原生取消不再显示为 `[object Object]`。仅输出受限的取消种类和安全传输代码，不输出任意对象字段、堆栈或凭据，也不改变原生错误结果及重试决定。
