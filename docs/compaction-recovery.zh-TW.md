# 上下文壓縮故障修復

由鎖定的 Harness 0.2.1-alpha.2 持有範圍選擇、工具配對、歷史替換與持久化；沿用 summarize 擴充點及校驗 SDK 的相容載入器，不升級依賴、不新增會話狀態機。

預設摘要預算為 32768 token（2026-11-10 使用者追加調整；額外預留 headroomTokens 維持 1024），小視窗限制為四分之一。預算包含服務計入的思考 token。模型明確支援 low 才使用低思考檔位，主工作設定不變；這可能降低部分服務的前綴快取命中率。明確耗盡預算後最多再嘗試一次雙倍預算，上限為 32768 與視窗二分之一的較小值。完整請求仍由介面檢查輸入及輸出是否容納得下。

空摘要、服務提前截斷及兩次耗盡預算不會提交檢查點。同一輪同一路由不再逐步重複自動摘要；空閒、切換路由或手動壓縮可重試。網路與權限錯誤維持原分類，不自動換模型。

手動失敗保留實際原因，介面只顯示一條歷史提示與預設收合的技術詳情，不疊加 Submit error。診斷保留用途、模型、預算、思考檔位、用量及字元數，不記錄正文或憑據。回歸涵蓋截斷、空回覆、取消、工具配對、原始指令、超窗、重啟與繼續任務。安裝驗收另行記錄；未重現同事原環境時不宣稱其問題完全排除。
