# 側欄會話懸停

會話行與捲動區域右側保留 4px 間距，移除疊加的右側外邊距。置頂和封存按鈕只在懸停或鍵盤焦點進入行內時占用空間，平時將寬度留給標題。

長標題在滑鼠進入整行時立即等速捲動，移除原有 600ms 延遲及關鍵影格起始停頓。移出後復位；系統開啟「減少動態效果」時不捲動，完整名稱仍可由資訊卡讀取。

資訊卡錨定整行右側，避免遮住操作按鈕。內容包含完整名稱、最近更新時間（相對時間及準確日期時間）、工作區別名與完整路徑。每次開啟刷新相對時間，不為每個會話長期執行計時器。缺失資料顯示未知或未關聯，不推測工作區。長內容換行，窄視窗內避讓邊緣；Esc 可關閉。

時間依序採用有效的 `updatedAt`、`lastMessageAt`、`createdAt`。重用既有會話資料和 Tooltip，不改變後端協定、儲存或會話刪除邏輯。
