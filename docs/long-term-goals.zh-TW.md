# 長期目標與計畫命令

在新任務或既有對話的輸入框中輸入 `/` 查看功能。支援搜尋、上下鍵選擇、Enter 確認、Esc 關閉與滑鼠點選。Windows 與 macOS 共用介面，不再顯示常駐目標表單。

- `/goal 目標與驗收標準`：建立並執行目標，使用 Harness 原生自動續跑上限（目前鎖定版本預設 256 輪），會消耗模型額度。
- `/goal pause`：暫停目標與目前執行，執行中也可使用。
- `/goal resume`：從儲存的進度繼續；應用程式重啟後需明確繼續。
- `/goal status`：按需查看目標、真實狀態、已用輪數與阻塞原因。
- `/plan 任務`：啟用計畫模式並研究任務，方案經使用者審閱後再實作。
- `/plan`：在既有對話選擇計畫模式；新任務會提示補充內容。
- `/plan off`：退出計畫模式，保留會話核准方式。
- `/compact`：使用既有上下文壓縮功能。

Harness GoalService 管理目標狀態、輪次與持久化；鎖定版本的 PlanModeController 管理計畫狀態。計畫指導與工具核准策略分別生效。前端僅傳遞明確命令，不從一般文字推斷授權或任務階段。目標標記完成後仍需檢查測試與實際結果。

選單依新增、指令、技能與常用任務分組。主選單提供檔案、目標、計畫、壓縮、權限、模型與匯出；技能與常用任務來自實際設定，不顯示尚未實作的功能。暫停、繼續與清除放在目標狀態列，退出計畫模式使用藍色計畫標記。

選擇目標或計畫後，輸入框顯示藍色前綴與提示；點擊前綴或在空輸入框按退格可退出。已有未完成目標時，選擇目標或點擊狀態列會開啟右側「編輯目標」分頁。大文字編輯區支援復原、儲存，關閉未儲存內容時會確認；儲存不會啟動或恢復目標。儲存衝突時保留草稿，可讀取最新目標再處理。一般訊息草稿保持不變。

檔案、權限與模型入口沿用既有功能；匯出將目前對話下載為 JSON。既有明確 `/goal edit 新目標` 與 `/goal clear` 指令仍可使用；清除目標保留對話與專案檔案。

斜杠選單也依技能、MCP 服務、內建工具分組顯示工具箱清單，支援名稱與描述搜尋。停用項目會標示狀態；點擊後進入對應詳情，瀏覽不會自動啟用或呼叫工具。專案技能依目前對話目錄讀取，各類清單獨立載入，部分失敗會提示重試。

計畫審閱使用獨立卡片展示 Markdown 正文，下方以編號選項提供「批准並實作」和「繼續規劃」，第一項標示「推薦」，選擇後按「傳送」。底部常駐輸入框，可直接填寫自己的想法；帶修改意見的回覆始終保留計畫模式。審批按鈕僅傳送 Harness 原生選項，計畫與執行狀態仍由 Harness 決定。
