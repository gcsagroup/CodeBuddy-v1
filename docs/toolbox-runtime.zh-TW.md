# 工具箱與對話同步

一般新對話跟隨工具箱目前啟用的能力。執行期間儲存技能、工具或 MCP 設定，不重建正在執行的作用域；下一則排隊訊息或下一輪傳送在執行前讀取目前設定。停用、刪除的工具仍受每次呼叫的目前策略限制。技能內容由 Harness 原生目錄及內容版本管理，不會抹除模型已讀過的歷史文字。

頂部與會話卡片使用同一個後端狀態，區分待套用、已連線與連線失敗。讀取狀態不初始化連線。其他視窗修改後，在重新取得焦點或可見時每三秒讀取一次；重試只使失敗的已選連線失效，正常服務繼續複用。執行中不可強制重連。

遠端 MCP 依完整單一服務設定取得官方 Harness `agent-preset-registry` 租約，包含憑證、工具過濾與逾時；最多快取 64 個可複用設定。修改、失敗或刪除一個服務不重啟其他服務。原生 scope 只投影會話選定的工具、資源與說明，不改共享 scope 的繼承。stdio 保持會話及目錄隔離。保留協定、Tasks、Apps、回執和審批適配，斷線不自動重放動作。資源授權核對投影定義並綁定來源連線代次，重連撤銷舊授權。

來源不明的舊名單保持自訂。明確切換「跟隨工具箱」只使用目前全域啟用項，保留但不執行舊名單與加密定義；切回自訂恢復原名單，仍套用目前全域停用與刪除策略。沒有舊名單時固定目前有效名單。刪除標記防止歷史副本復活，明確重新新增才恢復。重啟保留選擇，不改寫歷史、不重放工具、不刪除使用者設定。

已移除整組 MCP 快取入口與卡片獨立查詢／快取工具數量的路徑。Rust 獨立 MCP 工具繼續保留。Scrapling 等外部程序的相依損壞需修復其環境，同步與診斷不能替代安裝。

參考：鎖定 MIT 開發預覽版 Harness 0.2.1-alpha.2 的 [preset registry](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/preset/agent-preset-registry/README.md)、[MCP 生命週期](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/subsystems/mcp.md) 與 [工具清單變更協定](https://modelcontextprotocol.io/specification/2025-06-18/server/tools)。採用原生租約及作用域，保留產品適配，不另建 Agent 核心，未升級相依。

## 首次回覆與清單載入（2026-11-06）

桌面會話啟用 `backgroundMcp`：先建立選定連線的原生 scope，stdio 與遠端 MCP 在背景並行握手，普通回覆不再等待最慢的可選擴充。`connecting / ready / error` 與設定待套用分開顯示；舊載入結果通知不把背景連線誤報失敗。

`mcp-bridge` 持有就緒 Promise、診斷與銷毀。`search_mcp_tools` 回傳連線中的服務名稱，模型以結構化 `servers` 或精確工具名等待所需服務。等待可取消，不執行工具、不授予權限；角色篩選、策略、審批與回執維持原路徑。指定失敗服務時回傳實際診斷。首次失敗不自動反覆啟動，成功後的斷線恢復沿用原生命週期。

預熱與會話共用遠端設定身分，背景模式不是連線身分；相同 stdio 設定在連線中也可重用。移除、替換與關閉銷毀 scope，遲到結果不得恢復已刪選擇。執行中的設定變更於下一輪套用，每次呼叫仍檢查停用與刪除。無需持久化遷移、安裝依賴或恢復舊 Rust Agent。

新增連線 initialize（含程序啟動與協商）、tools/list、總耗時日誌；背景模式下會話準備日誌只表示 scope 准入。工具箱並行讀取技能、擴充、使用紀錄並逐步顯示。每組先掛載 24 項，接近底部追加，保留「載入更多」按鈕。搜尋與深連結使用完整目錄，編輯仍使用最新快照；後端目錄 API 本次未改為分頁。
# 擴充故障與預覽版本（2026-11-07）

編輯舊外部擴充時，缺省連線逾時於表單統一使用既有的 300 秒預設值，避免畫面與校驗不一致。明確無效值不自動修正；開啟或測試表單不寫回設定。

失敗通知依個別擴充記錄最近結果；其他擴充變化、排序、切換對話或部分結果不會重複提醒未變更的錯誤。確認恢復後再失敗或診斷改變會重新提醒。快取僅影響目前視窗通知，工具箱仍呈現真實連線狀態，不改權限或重連策略。

預覽後端記錄啟動時 runtime 原始碼指紋，以唯讀 `runtime/status` 提供執行身分與重啟提示。桌面每 30 秒及取得焦點時檢查；變更後提示任務完成再退出重啟，不自動中斷任務。指紋不等於套件簽章或完整建置證明，不掃描相依套件、工具二進位、測試與素材。啟動器沿用 SQLite 租約保護準備與執行期間，拒絕重複啟動並保留原啟動紀錄。

Scrapling 相依衝突於獨立 Python 環境修復，驗證 pip check、真實 MCP 初始化、工具發現與相關呼叫後，只替換該擴充執行檔路徑。離線寫入須先退出原後端、持有 profile 鎖並備份，再透過既有 Settings 儲存，保留其他設定。本次安裝已個別授權，不是應用啟動時自動安裝。
