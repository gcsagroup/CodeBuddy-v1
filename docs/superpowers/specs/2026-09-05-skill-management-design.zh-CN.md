# 技能管理与工具箱本地化设计

日期：2026-09-05。状态：书面规格已批准，用户已授权开发、测试与验收。

[繁體中文（默认版本）](2026-09-05-skill-management-design.md) · [English](2026-09-05-skill-management-design.en.md)

## 目标与依据

让用户通过页面或对话新增、下载、查询、编辑、删除技能，并让工具箱遵循当前语言。AI 发起删除，用户确认具体目标后执行。

已定位：ToolboxView 直接显示原始名称、描述，没有复用 SkillsView 与 ExtensionList 的翻译；验收技能的原始描述也是英文。sources.rs 已有部分文件 CRUD，但页面、下载和 AI 管理流程尚不完整；现有删除直接移除目录，不支持恢复。

采用共享 Rust 管理服务，经 ACP 和 AI 工具调用，保留现有目录与发现规则。仅补页面不能满足对话代办，仅让 AI 操作文件不能统一权限和刷新。参考 [OpenAI 官方技能文档](https://learn.chatgpt.com/docs/build-skills)（2026-09-05 查阅）的 SKILL.md、显式／隐式调用、范围及独立展示元数据；不推断其内部实现、不复制存储、不新建插件市场，也不声称已实测 Codex 全部管理功能。

## 功能约定

1. 页面支持搜索、来源／范围筛选、详情、新建、本地导入、链接下载；工具箱卡片进入同一管理界面。
2. 编辑稳定标识、描述、正文和展示文案，选择项目／全局范围；校验 frontmatter，保留未知字段及附属资源，不静默修改既有标识。内置与只读来源只能查看或复制后编辑。
3. 本地导入支持单个 SKILL.md 或完整技能目录。远端首版支持 GitHub 技能目录链接及 HTTPS SKILL.md 直链；GitHub 固定提交并记录来源，直链明确仅下载单文件。其他格式明确报不支持；需要登录时交由用户处理，不搜索凭证。
4. 安装展示来源、目标、文件清单和冲突。默认不覆盖，可取消或换名；覆盖需差异预览及确认。临时下载、校验后发布，失败不损坏原技能，也不执行下载脚本。
5. 删除显示确切目标、范围和来源，经确认后进入应用回收区，可恢复；恢复遇到冲突不覆盖。本次不提供永久清空、不修改无关删除 API 语义。
6. AI 安装、修改、删除复用相同服务。覆盖／删除必须关联真实用户确认事件及具体预览，模型自填 confirmed 不构成授权。取消不修改，目标版本变化后重新预览确认。
7. 操作后刷新工具箱和技能发现，下一次请求使用更新内容，不静默改变进行中回合。删除后不可再新加载，恢复后重新可用。

## 本地化与安全

自有界面、内置技能和工具文案完整支持繁体、简体、英文，语言切换立即生效，其他现有语言保留明确英文回退。第三方品牌、协议和稳定标识保留；展示名称／说明可本地化，详情可看原文。缺少译文标明原文并支持编辑展示文案，不擅自改写技能指令或上传内容，不保证第三方正文自动翻译。

使用解析后的路径和范围区分同名来源；写入前复验目标版本、权限和内容指纹。下载拒绝越界路径、符号链接逃逸、无效格式，限制大小、文件数和超时；HTTPS 请求及重定向拒绝本机和私有网络地址。新功能不扩大 AI 文件授权或只读会话权限。

## 接口边界

Rust 负责来源识别、列举／读取、预览、应用、回收及恢复；ACP 和 AI 工具负责授权与类型转换，不维护重复技能库。读取包含来源引用、范围、只读状态、版本、原始及展示元数据；预览包含目标、差异、冲突和受限操作凭据。应用重新校验凭据、版本与用户确认事件；成功返回真实目标及新版本，删除返回恢复引用。

沿用 ACP 错误机制，提供无效输入、只读、冲突、未授权、下载失败等稳定分类供 UI 翻译，详情不得泄漏凭证。复用现有类型，必要时增量扩展并生成 SDK，不引入旧 OpenAPI 客户端。

## 实施及验收顺序

1. 本地化：先回归测试，后修工具箱映射，验证三语切换及稳定标识。
2. 本地管理：新增、导入、查改、同名、只读、取消、越界、版本冲突、回收恢复及重载一致性。
3. 下载：有效来源、资源完整性、大小上限、网络失败、恶意路径、重定向、部分失败和覆盖回滚；真实下载后在对话调用。
4. AI：工具注册和路由、授权等待／取消、伪造确认拒绝、目标变化重新确认；自然语言操作与实际工具记录一致。
5. 完整门槛：相关 Rust／桌面全量测试、typecheck、lint、format、build，更新并执行 goose-self-test.yaml；从变更后源码启动 Electron，以真实鼠标键盘检查刷新、重启、文件、对话及日志。

新增回归未解决前不进入下一阶段。记录命令、cwd、退出码及通过／失败／跳过数。环境或桌面权限阻塞不算通过；只使用隔离测试数据，不改既有 MCP 和用户技能，不创建分支、不自动提交或推送。

## 展示元数据契约澄清（2026-09-05）

官方将展示名称／说明放在可选的 `agents/openai.yaml.interface`；本机内置 skill-creator 文件也可观察到此格式。[官方说明](https://learn.chatgpt.com/docs/build-skills)

本产品采用展示与执行标识分离，但不复制另一套存储：沿用 `SKILL.md` 的 `metadata.codebuddy.display`，内容为 locale 到 `{name, description}` 的映射。这是 CodeBuddy 约定，不是 OpenAI 标准。ACP 提供类型化展示数据及完整原始元数据；只有明确提交的展示字段才合并至对应节点。保留未知同级字段、其他语言、原始正文及附属文件；节点类型冲突明确报错。不更改稳定 `name`。缺少当前语言展示值时回退原文，不声称已翻译。
