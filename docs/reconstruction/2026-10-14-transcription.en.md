# Basic dictation integration

This batch adds `runtime/transcription.mjs` and `runtime/tests/transcription.test.mjs` in `D:\CodeBuddy-v1`, without changing the renderer, compatibility layer or settings module. The baseline is recorded in `source-baseline.json`. No branches, commits or pushes were created.

Existing microphone capture and chunking remain unchanged. `useAudioRecorder` produces 16 kHz mono PCM16 WAV and sends `{audio,mimeType,provider}` through `_goose/unstable/dictation/transcribe`, which returns `{text}`. The original input component still owns subsequent submission; transcription does not start an agent turn.

`new TranscriptionService(store,{resolveOpenAI?})` exposes `handles(name)`, `request(name,params,connection)`, `disconnect(connection)` and `close()`. Routes accept full or stripped prefixes for `dictation/config`, `dictation/secret/save`, `dictation/secret/delete` and `dictation/transcribe`. Disconnect cancels that connection's requests; closing cancels all requests.

The default OpenAI resolver uses explicit `OPENAI_BASE_URL` / `OPENAI_HOST` and protected `OPENAI_API_KEY`, or model connections with `id/catalogProviderId=openai`. It prefers the selected matching connection and leaves ambiguous selections unconfigured. It does not borrow credentials from an unrelated active Ollama or other provider. The integration layer may supply `resolveOpenAI({includeSecrets})`, returning `{baseUrl,apiKey?,headers?,configured}`. Configuration queries pass `includeSecrets:false` and need only metadata, avoiding unnecessary credential decryption. Requests resolve credentials when needed. OpenAI retains the original Settings > Models entrypoint.

Groq and ElevenLabs use the original dictation secret form and save to `state.config.GROQ_API_KEY` / `ELEVENLABS_API_KEY` using existing host DPAPI protection. Configuration queries disclose status only. Existing model keys remain valid: `OPENAI_TRANSCRIPTION_MODEL`, `GROQ_TRANSCRIPTION_MODEL`, `ELEVENLABS_TRANSCRIPTION_MODEL`. Defaults are `whisper-1`, `whisper-large-v3-turbo` and `scribe_v2`; explicit saved overrides retain precedence. ElevenLabs announced removal of `scribe_v1` on 2026-07-09, so the new adapter does not retain the retired source default. [Official changelog](https://elevenlabs.io/docs/changelog/2026/6/8).

The adapter uses standard Node.js `fetch` / `FormData`, native provider multipart protocols, and the installed Harness `validateWave` helper. Existing MIME types cover WAV, WebM, MP4, MPEG, MPGA and M4A. WAV follows the original frontend's canonical recording format. Audio is limited to 50 MiB, requests default to 30 seconds, responses to 1 MiB, and concurrency to four requests. Individual providers may impose lower upload limits. HTTP redirects are not followed. RPC errors omit upstream bodies, URL queries and credentials. This module does not persist recordings or transcripts.

`node --test runtime/tests/transcription.test.mjs` ran under existing Node.js 24: 7 passed, zero failed, exit code 0. Real temporary storage and a controlled local HTTP service verify original SDK shapes, multipart bytes and authentication for all three providers, model overrides, protected credentials across restart, gateway paths and queries, invalid audio, status failures, bounded responses, and disconnect/timeout/shutdown cancellation. Tests explicitly route all provider URLs to local fixtures; no real user account or microphone was used.

Local Whisper/SenseVoice execution and model download are not connected. Requests for `local` return `local_dictation_unavailable`, and configuration does not invent available local models. Real cloud recognition and desktop microphone acceptance require a separately configured service and user flow.

Protocol references: [OpenAI transcription](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create), [Groq speech-to-text](https://console.groq.com/docs/speech-to-text), [ElevenLabs transcript](https://elevenlabs.io/docs/api-reference/speech-to-text/convert). This batch added or installed no dependencies.
