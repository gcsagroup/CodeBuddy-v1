# 浏览器控制

网站开发完成后，如果你还没指定是否做浏览器测试，CodeBuddy 会先询问。选“开始浏览器验收”，它会打开网站并测试主要操作；选“只给我网站和启动方法”或跳过，就会给出入口和启动步骤，不打开浏览器。右侧自动验收在同一对话中复用一个标签；你手动打开的页面会保留。关闭测试标签后，下次验收会新建一个。

Windows 和 macOS 共用三种入口：

- 右侧浏览器：开发工具中的 `browser_control` 可打开 HTTP(S) 页面或工作区 HTML；文件面板的 HTML 工具栏也提供浏览器按钮。页面与当前聊天绑定。
- 独立窗口：在工具箱启用“浏览器控制 · 独立窗口”。使用锁定的 Microsoft Playwright MCP 和已安装的 Edge（Windows）或 Chrome（Mac），每次连接使用隔离浏览器配置。
- 用户浏览器：启用“浏览器控制 · 用户浏览器”，按 [Playwright 官方扩展说明](https://github.com/microsoft/playwright-mcp/tree/main/extension)安装扩展，并在浏览器选择和确认要连接的标签页。应用不复制个人浏览器配置。缺少扩展时连接会报错，需要先完成扩展配置。

可输入 `/` 选择已启用的工具；旧聊天需要通过现有扩展加载入口加载对应 MCP。模型负责选择入口，宿主不按用户句子关键词强制路由。

验收示例：创建含姓名输入框和“验证”按钮的网页，在右侧打开，观察控件后输入“浏览器测试”，点击验证并重新读取实际显示结果。只报告观察到的结果。独立窗口使用同一页面重复操作；用户浏览器在确认连接后重复操作。

导航后的 Playwright 结果可能是快照文件链接；调用 `browser_snapshot` 可读取页面快照，再按当前工具架构的 `target` 参数操作。右侧浏览器使用观察结果中的节点编号；遮挡目标将拒绝点击，导航后旧编号失效。输入只追加，不清空也不自动提交。动作派发不代表提交成功，结果不明时不要重复提交。

HTML 预览为本机临时地址，不是公网部署；仅开放 HTML 同目录内的网页资源，关闭标签或应用后失效。Playwright 自动输出缓存的清理阈值为 50 MiB，隔离 profile 不保留登录状态；关闭浏览器工具会释放页面。原生 Mac 验收与 Windows 结果单独记录，不以本机自动测试代替远端通过。
