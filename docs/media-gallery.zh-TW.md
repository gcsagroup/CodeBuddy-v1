# 生成媒體畫廊

同一輪回覆中已完成的圖片和影片整合到一個畫廊：主預覽、橫向縮圖、左右按鈕與目前位置。單一結果沿用直接展示。生成中的任務使用精簡進度，錯誤原因保留於各自工具記錄；不同輪次不合併。

點擊縮圖或左右按鈕切換，觸控板及觸屏可橫向捲動縮圖，不自動輪播。放大、另存新檔、外部開啟與側欄查看仍作用於目前項目。追加結果保留目前選擇。明確媒體回執不再受原本 8/12 項顯示上限截斷；一般文字的路徑候選仍有數量限制。

影片僅掛載目前播放器，其餘以編號與影片標識表示，不建立縮圖播放器。切換會停止舊影片，新影片不自動播放，只預載中繼資料。圖片縮圖延遲載入，主預覽限制高度，避免聊天隨產物數量持續增長。

本次僅調整展示，沿用工具回執與檔案校驗，不改生成、權限、持久化或 Harness 執行。參考 [W3C Carousel Tutorial](https://www.w3.org/WAI/tutorials/carousels/) 的使用者控制、按鈕命名與位置提示；使用既有 React、CSS、媒體元件，不新增依賴或複製第三方實作。美術品質及生成速度不在排版保證範圍。
