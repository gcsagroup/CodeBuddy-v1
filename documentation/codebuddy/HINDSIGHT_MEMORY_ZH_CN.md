# 可选 Hindsight 记忆索引

本地 Project Memory 负责内容、来源、审核、有效期和删除状态。Hindsight 仅补充语义候选排序；当前桌面、权限、任务状态和完成回执继续由宿主管理。

## 启用与范围

默认关闭。在后端启动环境或本机配置加入 `CODEPRO_HINDSIGHT_URL=http://127.0.0.1:18988`，重启后端。当前仅接受不含认证、查询参数和子路径的 loopback HTTP 根地址；设置页暂无独立开关。移除此设置即停用。

服务需要 `create_bank`、`list_documents`、`delete_document`、`sync_retain`、`recall` MCP 工具。宿主通过根 MCP 入口创建计算出的 bank，其余操作固定在该 bank。规范化项目路径和本地记忆配置目录共同决定 bank，模型不指定 bank。

启用意味着允许该本机服务索引有效项目记忆。Hindsight 若配置云端抽取模型，记忆内容也会发往该供应商；本集成本身不复制模型密钥。用户范围的偏好不复制到项目 bank。

## 行为

- 保存先完成本地提交。项目记忆写入、编辑、删除和搜索触发后台对账，按完整版本指纹增删外部文档。
- 同项目后台工作合并；失败每 30 秒重试。进程退出时结束，下一次记忆操作重新对账。
- 查询保留本地文字匹配，再补语义候选。网络预算 1.5 秒，失败重新读取本地结果并明确降级。
- 外部命中必须与本地当前有效记录 ID、版本一致，最终正文来自本地；旧版本、删除、过期或证据失效记录不被恢复。
- 相似候选不是答案证明，无依据应说未知。不自动调用昂贵的 `reflect`。

## 限制

首次索引完成前，语义候选可能不完整。服务离线时本地删除立即生效，外部副本等待恢复并对账后删除。关闭整合不会删除外部数据；移动项目或更换配置目录会产生另一个 bank，旧 bank 需明确清理。

本次增强明确的记忆搜索，任务开始时的原有本地记忆注入仍使用原机制。按需隐藏只读工具定义不等于撤销权限；执行校验使用当前有效目录，并保留宿主明确拒绝。

## 验证

沿用现有环境，在同一 worktree 执行 `cargo test -p goose --lib project_memory --jobs 1 -- --test-threads=1` 和 `cargo test -p goose --lib read_only_analysis --jobs 1 -- --test-threads=1`。

真实服务回归默认忽略：经允许使用本机模型和合成资料后，运行 `cargo test -p goose --lib hindsight_live_roundtrip_update_delete_and_isolation --jobs 1 -- --ignored --test-threads=1`，服务为 `127.0.0.1:18988`。

2026-09-30 已使用本次重建后端和 Kimi 完成真实保存、新对话改写查询、续聊未知项及 Hindsight 离线回退验收。会话最终状态均为 finished，并核对本地记录、实际工具回执及用户可见回答。真实服务回归还覆盖更新、过时版本拒绝、隔离和删除同步。

范围限制：仅少量合成案例，不代表所有模型均通过；自然语言删除/清空的完整会话尚未验收。检索调用约 40–195 毫秒，离线回退约 1.55 秒；完整任务还包含模型等待和完成核验，本轮出现过超过两分钟的模型等待及两次预检暂时不可用。

参考：[Hindsight MCP 官方文档](https://hindsight.vectorize.io/developer/mcp-server)。

## 本次配套修复

只读续聊的执行权限依据当前有效工具目录判定，按需隐藏定义不再误当撤销工具；明确拒绝仍保留。记忆任务维持 8 轮上限，最终回答保留 1 轮，避免沿用开发任务保留 5 轮而在第 4 轮过早移除工具。任务协议的 inspect 及格式错误回执提供参数结构示例；模型仍须选择真实来源与证据，宿主不自动补齐或接受错误字段。

纯记忆工作使用现有 ToolAction 任务类型，不再被 SimpleChange 的工作区文件差异门槛拦截。完成时仍核对有效需求版本、具体记忆目标和记忆模块回执；同一记忆回执不能证明另一条记忆或文件已交付。
