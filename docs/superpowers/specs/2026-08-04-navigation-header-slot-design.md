# CodeBuddy 侧栏顶部槽位设计

## 问题

统一模式隐藏 `Code / CodePro` 切换器时，同时删除了切换器所在的 48px 顶部容器。应用级侧栏折叠按钮仍绝对定位在侧栏左上角，导致它覆盖第一项“新对话”。

## 设计

- 侧栏始终渲染高度至少为 48px 的顶部槽位。
- 非统一模式在槽位中显示 `WorkspaceSwitcher`。
- 统一模式保留槽位但不渲染切换器，为应用级折叠按钮和窗口拖拽区域留出稳定空间。
- 导航项目、聊天记录和设置区域的结构与交互保持不变。
- 使用现有间距、颜色和尺寸令牌，不引入新的绝对像素体系。

## 无障碍与响应式

- 折叠按钮继续使用原有可访问名称和键盘行为。
- 顶部槽位不增加可聚焦元素。
- 展开侧栏在统一模式和双工作区模式下使用相同的内容起始位置。

## 测试

- 增加布局辅助函数或组件测试，证明统一模式和非统一模式都保留顶部槽位。
- 证明统一模式不显示工作区切换器。
- 运行相关 Vitest、TypeScript 类型检查和 Prettier 检查。

## 非目标

- 不移动应用级侧栏折叠按钮。
- 不调整导航宽度、菜单顺序或聊天记录布局。
- 不修改 CodePro 任务栏。
