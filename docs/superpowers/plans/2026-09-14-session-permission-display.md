# 工作階段模式與權限說明

日期：2026-09-14。預設文件為繁體中文；另有[簡體中文](2026-09-14-session-permission-display.zh-CN.md)及[English](2026-09-14-session-permission-display.en.md)。

## 問題與修正

「自主」原本承諾可自由修改所有檔案，「手動」則聲稱所有工具都要確認，均未準確反映現有規則。修正文案：自主在目前權限內自動執行，受限制或範圍外的操作可能需要確認；手動會對尚未由權限規則或唯讀政策允許的操作詢問。本次不修改後端審批決策、拒絕規則或授權重用。

預設模式只用於新工作階段。`new_session.rs` 建立時讀取預設值，`load_session.rs` 與 `execution/manager.rs` 恢復持久化模式。`preferences/save` 不會更新既有工作階段。英文設定說明原本已正確，但原生驗收發現其他語言仍沿用舊譯文，本次同步 16 種語言的標題與說明。

全新設定的真實 ACP 回應以 `value: null, isMutable: true` 表示尚未設定。原本前端僅處理空清單，因此四個模式選項被禁用。新增回歸測試確認修正前失敗；現在僅此可編輯空值採用後端相同的預設自主模式，不自動寫入設定。托管值仍禁用，未知值取消選中並顯示「尚未同步」。使用者選擇後，仍透過既有 revision 校驗流程儲存。

前端原本丟棄標準 ACP 回應的 `modes.currentModeId`。現在新建與載入均透傳至 `Session.goose_mode`，並依通知中的工作階段 ID 處理 `current_mode_update`。取消後仍接收模式狀態通知；既有晚到內容封鎖不變。缺少或未知模式顯示「尚未同步」，不以全域預設值代替。

對話輸入區上方顯示目前模式，可展開查看目錄說明。內容使用實際工作階段繫結：已繫結專案仍受工具規則約束；根目錄不是專案寫入授權；未繫結表示尚無專案寫入授權。一般工作目錄僅表示執行位置，不代表所有操作獲准。現有確認元件的原因、來源與作用域展示直接沿用。

## 驗證與限制

隔離 Electron 原生驗收通過：未設定時四個模式選項可用；手動預設值儲存後，真實 ACP 讀回 `approve`、revision 1；未傳入明確模式的新工作階段 `20260914_2` 採用手動，舊工作階段保持自主。切換、刷新與應用程式重啟後均一致。新工作階段只補入一則標示清楚的測試訊息以便歷史列表顯示，沒有修改模式，也沒有發送模型請求。一般工作目錄及未繫結 CodePro 範圍完成原生核對；專案與根目錄的不同說明另由元件測試覆蓋。證據見 `mode-native-acceptance.json`、`mode-new-session-acp.json` 及對應 `.txt`／`.png`。
