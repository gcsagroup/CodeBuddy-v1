# 桌面虛擬寵物

設定 → 虛擬寵物提供小熊貓、奶油貓和白狐。小熊貓為預設；點選卡片預覽，點選「設為桌面寵物」切換形象並顯示，也可單獨顯示或隱藏。既有自訂選擇保留，早期 `buddy` 預設項遷移為 `red-panda`。

支援待機、揮手、跳躍、工作、等待輸入、受阻、檢查完成及觀察方向。拖曳移動，點選打招呼，連按兩下跳躍。任務提示使用 ACP 的結構化聊天狀態；點選提示開啟對應聊天。可在設定中減少動畫。

完成提醒在對應聊天實際顯示且視窗取得焦點後才標記已讀；點選跳轉本身不提前清除提醒。隱藏聊天或背景視窗不會誤清除提示，下一輪的新完成記錄會再次提醒。移除聊天時同步撤下該聊天的寵物提示。

一個寵物承載可展開的聊天清單，優先顯示等待使用者處理、受阻、未讀完成、工作中的聊天。每條顯示標題及真實活動（思考、撰寫回覆、目前工具、整理上下文等），已有結構化工作階段時一併顯示；完成項附勾選。尚未命名的新聊天顯示首條請求摘要。點選哪一條就前往哪一條，不推算百分比或從回覆文字推斷完成。

## 素材與建立

完成勾選與側邊欄綠色未讀點使用同一份完成記錄，實際查看聊天後一起清除。Agent 透過 `ask_user_question` 提問時，寵物顯示「等待你回覆」與問題摘要，點選前往對應問題；查看不會代替回答。工作中可點選「暫停」，沿用聊天停止操作；「繼續跟進」開啟原聊天，供使用者送出後續要求。

「自訂寵物」在目前視窗建立聊天，預填形象、名字、顏色、畫風、動作與補充要求範本。使用者修改後送出，預填不會呼叫模型，也不另開視窗。

內建素材隨應用程式封裝，日常顯示不依賴圖像服務。三個角色根據使用者確認的原創概念圖製作，透過 ComfyUI 的 Qwen Image 2.1 圖生圖工作流程產生連續姿勢。網頁參考僅用於風格研究，沒有複製第三方成品素材。

「自訂寵物」開啟 CodeBuddy 的主 Agent 聊天。Agent 先詢問未明確的形象、顏色、風格和名字，再呼叫內建 `create_desktop_pet`：`prepare` 傳回素材要求，`assemble` 裝配真實圖像、校驗並註冊預覽包。新包會自動出現在設定中，也可手動重新整理；使用者預覽並點選「設為桌面寵物」後才啟用。

主 Agent 負責整個流程，透過內建 `generate_image` 呼叫設定中的 ComfyUI，先產生角色參考圖，再產生八組動作網格。聊天模型負責理解需求與撰寫提示詞，ComfyUI 負責產生像素，裝配工具負責校驗與註冊。設定、支援的參考圖格式與任務查詢見[內建圖像生成](image-generation.zh-TW.md)。缺少圖像服務時應具體說明，勿將複製靜態影格當作新動畫。

建立聊天會使用設定頁顯示的自訂素材目錄作為明確工作區，並預填素材要求供使用者編輯後送出。若缺少圖像工具，可提供自己已有的圖像服務與工作流程，再由 Agent 檢查實際可呼叫性；服務位址、憑證與可用模型不會從 Codex 自動繼承。

自訂包放在設定頁顯示的目錄中，以穩定英文 ID 命名資料夾，僅含 `pet.json`、`sprites.png`。保留 ID：`buddy`、`red-panda`、`cream-cat`、`white-fox`。

`pet.json` 為版本 1：`schemaVersion: 1`、`image: "sprites.png"`、`columns: 6`、`rows: 8`、`cellWidth: 192`、`cellHeight: 208`、`fps: 6`，另含 `id`、`name`、`description`。PNG 為透明 RGBA，尺寸 1152×1664。列順序對應上述八組動作；觀察列依次為上、右上、右下、下、左下、左上。每格至少有 2 像素透明邊緣，每個動作至少有 3 個不同的真實姿勢。

素材損壞會顯示錯誤並保留已驗證版本。內建包異常時可回退至其他有效寵物；沒有有效素材時不開啟空白浮動視窗。

## 素材裝配

`runtime/assets/assemble-pet.py` 僅裁切、縮放、排列生成圖，並匯出預覽與檢查記錄，不繪製角色；原 `ui/desktop/scripts/assemble-pet.py` 保留為同一實作的入口。內建工具只接受聊天工作區內的圖像，暫存目錄校驗成功後一次發佈完整包，不覆寫既有 ID，也不自動切換寵物。像素校驗不等於角色一致性或動作語義驗收，仍須預覽。原圖、工作流程及本機驗收檔案位於 `target/pet-redesign`，不隨應用程式發佈。
