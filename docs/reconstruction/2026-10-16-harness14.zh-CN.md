## 清理边界

按用户授权，删除 11 个旧 Rust crate 中的已跟踪文件，包括 Agent、CLI、Provider、本地推理、原生 SDK 及专用测试辅助。连同专用入口共删除 875 个确认没有未提交修改的文件；保留 `crates/goose-mcp` 全部独立工具。整目录删除曾被自动审批拒绝，随后缩小为仅删除经核对的 Git 已跟踪文件，未递归删除未知本地文件。

执行、调度、完成、计量、压缩继续由已锁定的官方 Harness 插件主导。沿用现有 `compaction-basic` 单检查点兼容补丁，不新增摘要器或 CodeBuddy 完成判定。上游为 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)，本批未升级依赖。
