# 介面重連與任務執行

重新整理介面或 ACP WebSocket 斷線後，已接納的任務繼續由同一個 Harness 執行。重新連線時，桌面載入原會話，回放日誌並接續即時訊息，不重複傳送使用者請求或生成圖片。

`runtime/server.mjs` 管理連線與待答 RPC；`runtime/session-connection.mjs` 僅負責活動會話的客戶端投遞。`runtime/compat.mjs` 在 session/load 完成後綁定客戶端並提供真實 activeRunId。前端使用既有恢復通知載入目前會話，清除已結束請求的過期執行顯示。

權限、問題與配方參數沿用原生請求、權限範圍與期限，等待重連後重新呈現。瀏覽器及桌面命令不自動重播。主動停止及服務關閉仍沿用原生取消。後端程序崩潰、系統重啟後的自動續跑不在保證範圍，既有會話無需遷移。

工具錯誤保留可讀原因；結構化取消不再顯示 `[object Object]`。僅輸出受限的原生取消種類與安全傳輸代碼，不輸出任意物件欄位、堆疊或憑證，不改變原生結果及重試決定。

回歸涵蓋斷線持續執行、歷史與即時訊息銜接、明確停止、決策期限、桌面命令不重播及前端重新載入。真實寵物驗收與截圖位於本機 `.local/session-reconnect-20261110/`，不納入提交。
