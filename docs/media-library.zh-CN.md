# 素材库：视图、容量与删除

左上菜单进入素材库。可切换“按时间排列”和“按工作区分类”，各视图均按生成时间从新到旧排列，同时间以稳定 ID 排序；工作区按目录排序。搜索、类型和项目筛选仍可组合使用。

卡片显示文件大小，页面右上角刷新按钮左侧显示全库素材数量与所有文件大小；刷新按钮采用与统计一致的小字号和紧凑间距，不再重复显示长按提示和当前结果容量；工作区标题复用对话侧栏的自定义名称（未命名时用文件夹名），右侧显示该区匹配素材容量。容量在分页前计算，不限于已加载的 48 项。统计的是已登记、可访问生成文件的逻辑字节数，采用 KB/MB/GB/TB/PB 单位（1024 进制），统一保留一位小数，同路径去重；缺失文件、未完成任务、未被回执登记的文件及其他工作区文件不计入，不等同于磁盘实际分配空间。

默认隐藏复选框和批量操作栏。鼠标长按素材卡片约 500 毫秒进入多选并选中该素材；移动超过 8 像素或提前松开取消长按，普通点击仍可预览。也可聚焦卡片后按空格或 Enter 进入。“全选”选中当前筛选条件下的所有素材，包含未加载分页；工作区标题旁的按钮在未全选（含部分选中）时显示“+”，点击选择该区所有匹配素材；全选时显示“−”，再次点击清除该组全部选择，保留其他工作区的选择。全选状态依据完整素材 ID 集合，不依赖可选容量统计字段。删除按钮右侧的“取消选择”清空选择并退出多选，不再显示独立退出按钮。确认后按最多 500 项分批调用删除接口。修改筛选条件、切换视图或刷新会清除选择。点击“删除选中”后，确认框展示数量、大小及完整路径；取消或 Escape 不删除文件，默认焦点位于取消按钮。

**“永久删除”会直接删除选中的生成文件，无法撤销，不经过回收站。** 对话、工作区和生成回执保留。缺失文件只从素材库移除；删除失败逐项报告，可刷新后重试。删除过程中确认框不能关闭。成功后刷新容量和列表。

## 统计与选择效率

每个回执目录最多并发 8 个元数据任务，不读取素材文件内容、不遍历工作区其他文件。已解析回执按文件大小、修改时间、变更时间及 inode 校验缓存；最多保留 4096 条、原始 JSON 合计 32 MiB（解析后实际内存可能更高），不新增持久索引。每次查询重新读取文件大小元数据，同一请求中复用工作区真实路径和同路径文件查询，避免缓存陈旧容量；工作区统计单次分组。刷新可反映外部文件增长或删除。

列表仍按 48 项分页，仅全选请求使用 `all: true` 返回所有匹配素材元数据，不加载未显示素材的图片/视频内容。全库数量含缺失文件的可见记录，缺失文件贡献 0 字节。旧后台缺少统计字段时显示“—”，不能当成 0；需重启后台获取新字段。

## 实现范围

- `runtime/media-library.mjs`：扫描投影、分页排序、容量聚合、受限文件删除和逐项结果。所有删除对象由服务端从稳定素材 ID 解析，客户端不能提供路径。
- `runtime/compat.mjs`：新增 `_codebuddy/media/delete`，列表读取删除标记。
- `state.json` 新增可选 `mediaLibraryDeleted` 字段：素材库唯一持有，记录已删除输出 ID；不修改任务回执，不重排输出数组，旧数据无须迁移。文件删除和标记写入非跨文件事务；写标记失败时报告失败，重试将缺失文件标记移除。
- `ui/desktop/src/components/media-library/MediaLibrary.tsx`：视图选择、容量展示、复选框、原生模态确认与结果反馈。
- 回归：`runtime/tests/media-library.test.mjs`、组件测试、现有浏览器素材库夹具及 `media-library.browser.spec.ts`。

拒绝符号链接、目录联接及非普通文件的删除，不递归清理生成目录。此次仅操作测试夹具，未删除真实素材。与本机其他进程恶意并发替换目录之间不提供操作系统级原子路径锁定保证。
