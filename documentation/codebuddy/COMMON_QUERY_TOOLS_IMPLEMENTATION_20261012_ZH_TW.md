## 行為

- 每次主要模型請求重新取得主機時間，包含一般聊天及壓縮／恢復後的請求。投影不寫入歷史；明確禁止工具的回合維持原有受限上下文。
- `time_now` 回傳 UTC、當地時間、日期、星期、IANA 時區來源及取樣時間；支援夏令時間。時區不作為實際位置證據。
- `location_resolve` 回傳城市／行政區候選與座標。同名地點交由模型詢問使用者。
- `weather_get` 查詢當前天氣或含今天的 1–7 日預報；地點省略時使用已設定的預設查詢城市，未設定就回傳 `needs_location`。
- 一般聊天只開放這三種已啟用的查詢；沿原權限與回執機制派發，不開放工作區修改或桌面控制。語意分類器依問題目的選擇聊天路徑，沒有新增關鍵字路由。

設定 → 一般 →「時間與天氣」可設定城市、兩位國家代碼、IANA 時區、攝氏／華氏及允許連線。設定沿既有 ACP config 邊界儲存，後端驗證參數；每次工具呼叫重新讀取。工具箱顯示「常用查詢」。沒有 GPS／IP 自動定位或背景追蹤。

## 資料與失敗處理

首版使用 [Open-Meteo API](https://open-meteo.com/en/docs) 及[城市解析 API](https://open-meteo.com/en/docs/geocoding-api)。[免費服務限非商業用途](https://open-meteo.com/en/terms)，商業發行需接入符合用途的付費方案／供應商。此版沒有付費 API 憑據設定。

回傳模型天氣資料及原始單位、來源、資料有效時間與查詢時間。缺值保留 null；不將查詢時間稱為觀測時間。地名快取 24 小時，天氣快取 5 分鐘，最多 256 筆；預報跨當地日期重新查詢。刷新失敗可回傳一小時內的舊天氣，但 status=stale、原時間與刷新錯誤必須保留。關閉連線在讀取快取前生效。HTTP 請求限 12 秒，整個工具限 25 秒，取消即中止等待；429 記錄 Retry-After 冷卻時間，不立即重試。

時間與天氣值由主機／供應商產生，模型負責理解、選擇查詢和說明結果；模型文字不是工具執行證據。遠端後端留空時區時使用該主機時區，需明確設定顯示時區。
