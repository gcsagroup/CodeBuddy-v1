# 每轮执行回执与迟到快照

Harness 原生日志继续持有工具调用、结果和轮次边界。适配层在每次准备模型请求时，从目标会话的日志投影本轮和上一轮的有限回执索引，沿用现有 `commandEvidence` 补充本轮结构化进程退出事实。每轮最多展示最近八项工具调用的标识与状态，不复制参数、代码、输出或命令正文。索引使用原生动态系统段，每次请求只保留当前版本，不作为不断追加的运行时历史快照；原日志不修改。

现有系统行为段继续要求实际执行与据实报告，回执索引只提供结构化事实。本轮没有回执时，模型应实际执行用户要求的修改与验证，或明确尚未执行。上一轮已返回的操作作为已有记录提供；用户明确要求重做或需要修复时仍可再次操作。待处理、错误、中止和结果未知的调用不能当作已完成副作用。`isError:false`只表示工具返回，不能代替进程退出码或整个任务验收。模型回答和代码示例不参与事实投影。

工具尚在执行且原生插话可用时，忙碌期间新写入的补充输入通过既有steer入口进入当前轮的下一步，不等到本轮结束再重新构造任务。没有运行中工具时仍按普通队列等待。正在编辑、暂停、连接或取消屏障、Escape代际不匹配及已返回的工具都不能触发自动插话；历史工具不作为当前轮运行事实。拒收或回执不确定时保留输入并暂停，不自动重投。原生Harness仍唯一决定何时消费输入以及执行、取消和完成。

桌面在忙碌期间写入队列的输入保存可选`queuedWhileBusy:true`，通过ACP已有`_meta`的`codebuddy/input-origin=queued-while-busy`传递。Compat仅识别这个确定值，Harness只在当前请求的回执上下文中投影`inputOrigin`，不改写用户正文或重新解释意图。普通输入和用户主动重试不携带该来源。旧队列缺少字段时保持原行为，畸形可选字段被丢弃，不阻断原文本。这个来源只是模型理解延迟输入的背景，不授予权限、不裁定重复执行是否合法。

2026-11-16 已批准的补充受控模式默认生效：原生当前轮消费第二项用户输入后，或历史会话消费带队列来源的后续轮输入后，非只读提案均复用原生审批逐次确认。首次会话的启动队列不算补充。审批卡显示精确参数及最近八项回执，较长历史命令明确截断；当前提案不截断。既有会话许可和全局允许不能跳过本次确认，仅有“本次允许”和“拒绝”。禁止审批的会话不绕过原生规则；取消、失联或答复未知不执行该提案。普通新轮恢复原规则；已开始的工具不回滚。模型仍可提出重复操作，但未经批准不会产生重复副作用；用户可以批准有意重做。没有通过字符串裁决命令是否等价。

原生轮次结束仅证明执行已结束。宿主保留未验证报告，包括零工具回答；桌面不再展示每轮固定的“任务结果未独立验收”提示条，也不因旧的通过记录改成PASS。结束通知也仅报告本轮执行结束。模型总结不是验收事实。本批没有恢复已移除的复核模型、外部验收脚本或第二执行器，也不保证任意模型的自然语言永不出错。尚无明确独立验收合同的任务保持未验收。

自动插话沿用`isConversationTurnStart`识别真实输入边界。ACP中工具返回也可以使用user角色；仅按角色切片会丢掉仍在执行的工具，尤其是工具发现后的批量消息。工具回执不构成新的人类指令，必须保留该轮尚未返回的工具。

Windows 原生执行器为缺省 Python 子进程声明 `PYTHONIOENCODING=utf-8`，保留显式设置；设置限于标准流，保留原有文件默认编码。Windows Python 管道原先采用GBK，“状态”的GBK字节又碰巧合法UTF-8，事后猜编码不能可靠恢复；在产生输出前明确编码才消除这类歧义。原有未知旧程序的兼容解码、原始字节偏移及截断仍保留，不能据此承诺任意二进制程序的混合编码都能自动识别。

桌面按 `(sessionId, runId)`维护最新快照。来自聊天通知、控制请求或重新连接刷新的一份完整快照，如果序号低于已应用序号，返回现有投影且不通知订阅者。相同序号的事件事实冲突、无效版本或无效身份仍然拒绝，不能以丢弃旧快照为由掩盖协议错误。

回归位于 `runtime/tests/execution-receipts.test.mjs`、`runtime/harness/test/empty-response-recovery.test.mjs`及桌面的`runProjection.test.ts`、`runCommands.test.ts`。真实模型验收应核对文件变化、工具结果、追加输入消费次数和副作用计数，不能只看助手说“通过”。

设计对照：[LangGraph 官方说明](https://github.com/langchain-ai/docs/blob/main/src/oss/langgraph/functional-api.mdx)强调恢复时复用结果及副作用幂等；[审批示例](https://github.com/langchain-ai/docs/blob/main/src/oss/langgraph/interrupts.mdx)将确认放在副作用前。本项目复用现有Harness，不引入其依赖或重放引擎。[Python官方文档](https://docs.python.org/3/library/sys.html)说明Windows非控制台管道使用区域编码及显式UTF-8覆盖。聊天通知与控制刷新使用不同连接，不能假定跨连接按顺序到达。
