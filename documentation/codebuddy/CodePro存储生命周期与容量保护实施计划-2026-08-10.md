# CodePro Storage Lifecycle and Capacity Protection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make storage usage visible, keep reclaimable data bounded, prevent disk exhaustion, and guarantee that sessions, memory, credentials, and nonterminal runs are never silently deleted.

**Architecture:** A Rust storage service inventories backend categories and delegates cleanup to existing state-aware policies. Electron owns Chromium session cache measurement/clearing through official APIs. The desktop merges both reports into one settings view, uses preview-before-cleanup, and blocks large writes when the target volume falls below the reserved free-space threshold.

**Tech Stack:** Rust 2021, serde, fs2, sqlx SQLite, existing CodePro cleanup stores, ACP custom requests, Electron 41.1.0 Session API, React, TypeScript, Vitest, Testing Library, Playwright.

## Global Constraints

- This plan starts only after the unified-path acceptance plan passes.
- Reuse current policies: terminal run 30 days/2 GiB; completed audit/idempotency 30 days and 4,096 records per session/scope; project memory 500 entries/2 MiB per project; Rust logs 14 days; startup diagnostics 20 files.
- Electron cache soft budget is 512 MiB per profile; MCP and rebuildable model metadata cache share a 256 MiB soft budget. Downloaded model files are protected assets and require explicit per-model deletion.
- Sessions are retained until explicit user deletion; no count-based automatic deletion.
- Current, planning, running, paused, or reviewing runs are never automatically deleted.
- Unresolved audit/idempotency records, project memory, downloaded models, credentials, plugins, and legacy migration roots are excluded from automatic cleanup.
- Free-space reserve is 5% of target volume, clamped to 1–5 GiB.
- Electron cleanup names cache data types explicitly; no parameterless `clearData()` or `clearStorageData()` calls.
- Manual legacy-root deletion requires a separate user confirmation showing exact absolute paths and is not executed during automated acceptance.
- Preserve unrelated worktree changes. Do not create a branch, commit, push, or delete the current user's real data.
- Record every task under `documentation/codebuddy/evidence/CP-STORAGE-02/`; do not create Git commits before user inspection.

export async function getElectronCacheUsage(ses: Session) {
  return { bytes: await ses.getCacheSize(), softBudgetBytes: 512 * MIB };
