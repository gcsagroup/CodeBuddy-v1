# 側欄與思考強度互動

工作區位於任務上方。對話懸停顯示置頂和封存，右鍵保留完整選單。置頂留在原分組，最新置頂排最前，取消後恢復活動順序。

資料夾懸停提供更多和新增對話。選單包含置頂、重新命名和封存其中對話；封存前確認完整數量，不刪除檔案，部分失敗可重試剩餘記錄。

聊天思考強度暫存於應用程式記憶體，下一次明確傳送時才儲存至原連線／模型設定。拖曳或鍵盤調整不發送設定請求，不改變執行中任務；自動續跑不消耗調整。結束應用程式會丟棄未傳送調整。儲存失敗不啟動任務，保留草稿供重試。

模型清單搜尋框旁提供重新整理；防止重複點擊，失敗保留原清單和選擇，可重試。

資料夾名稱左鍵用於展開／收合對話；左鍵點選旁邊「更多」中的「開啟資料夾」，會在系統檔案管理員開啟專案真實路徑，沿用對話選單的入口。失敗時顯示錯誤，可重試。
