# 每輪執行回執與遲到快照

Harness 原生日誌繼續持有工具呼叫、結果和輪次邊界。配接層每次準備模型請求時投影本輪及上一輪最近八項呼叫的標識、狀態與本輪結構化程序結果，不複製參數、程式碼、輸出或命令正文。索引使用原生動態系統段，每次請求只提供目前版本，不累加為歷史快照；不修改原始日誌。

既有系統行為繼續要求實際執行與據實報告，回執索引僅提供結構化事實。本輪無回執時，模型應實際執行要求的修改與驗證，或明確表示尚未執行。上一輪已返回的操作是既有記錄，明確要求重做或修復時仍可再執行。待處理、錯誤、中止與結果未知不代表副作用已完成。`isError:false`不能代替程序退出碼或整個任務驗收。回答和程式碼示例不會成為執行事實。

工具執行中且原生插話可用時，忙碌期間新增的補充輸入由既有steer交給當前輪下一步，不延後至新一輪重建任務。沒有執行中工具則維持普通隊列。編輯、暫停、連線或取消屏障、Escape代際不符及歷史／已返回工具都不能觸發自動插話。拒收或回執未知時保留並暫停，不自動重送；原生Harness仍持有輸入消費、執行和結束權威。

忙碌時寫入桌面隊列的輸入保存可選`queuedWhileBusy:true`，透過ACP既有`_meta`欄位`codebuddy/input-origin=queued-while-busy`傳遞。Compat辨識確定值，Harness僅在該請求的回執上下文提供`inputOrigin`，不改寫正文。普通輸入與主動重試不帶此標記；舊資料缺欄維持原行為，無效可選欄位降級但保留文字。來源僅提供背景，不授權或裁定重做是否合法。

2026-11-16已批准的受控補充模式預設生效：同輪第二項原生使用者輸入，或歷史對話帶隊列來源的後續輪，令非唯讀提案逐次審批。首次啟動隊列不算補充。既有審批卡展示精確參數及最近八項回執，過長歷史命令明確截斷，當前提案完整保留。會話許可及全局允許不能跳過本次確認，只有本次允許／拒絕。禁止審批、取消及未知答覆不執行，普通新輪回復原規則，已開始操作不回滾。不按命令字串推斷等價；模型仍可提出重複，但未批准不產生副作用，使用者仍可批准有意重做。

原生結束只表示執行結束；宿主保留未驗證報告，包括零工具回答。桌面不再顯示每輪固定的「任務結果未獨立驗收」提示列；通知僅表示本輪執行結束，不由歷史記錄或模型總結推導目前PASS。不恢復已移除的複核模型、外部腳本或第二執行器；無明確驗收合同的任務保持未驗收，不保證任意模型的文字永不出錯。

自動插話沿用isConversationTurnStart辨識真正輸入邊界。ACP工具回執也可使用user角色，不能被當成新的人類指令而切掉同輪尚未返回的工具，尤其是工具發現後的批量訊息。

Windows原生執行器為缺省Python管道聲明PYTHONIOENCODING=utf-8，保留明確覆寫；設定限於標準流，保留原有檔案預設編碼。原GBK「狀態」位元組亦能合法解碼為錯誤UTF-8，應在輸出前確定編碼。舊程式相容解碼、原始位元組偏移及截斷不變，不保證任意混合編碼能自動識別。[Python官方文件](https://docs.python.org/3/library/sys.html)說明管道與編碼覆寫；[LangGraph審批設計](https://github.com/langchain-ai/docs/blob/main/src/oss/langgraph/interrupts.mdx)說明副作用前確認；本專案沿用Harness，不引入該依賴。

桌面依`(sessionId,runId)`保存最新完整快照。聊天通知、控制回覆或重連刷新若帶來較舊序號，直接返回現有投影且不通知訂閱者。相同序號的事件事實衝突、無效版本與身份仍拒絕，保留協議保護。

回歸包含`runtime/tests/execution-receipts.test.mjs`、原有空回應恢復檢查，以及桌面投影和控制命令測試。真實驗收要核對檔案、工具回執、輸入消費與副作用次數。

設計對照：[LangGraph 官方文件](https://github.com/langchain-ai/docs/blob/main/src/oss/langgraph/functional-api.mdx)說明恢復時重用完成結果與副作用冪等。本專案只採用回執重用原則，不引入其引擎或按命令字串去重。不同連線的通知與刷新不能假設順序一致。
