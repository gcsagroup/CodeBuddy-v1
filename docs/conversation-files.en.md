# Conversation file card

Referenced files and recorded changes share one card after a completed turn. Each path appears once; Windows identity comparison is case-insensitive while macOS preserves case.

Recorded changes show added/removed lines and open the saved turn evidence. View changes opens the full turn. References are shown only after inspection within the current workspace; they open the file without contributing to edit totals. Historical edits keep their saved receipts rather than recalculating from current file contents.

The card initially shows three rows, with an expand action for additional files and a collapsible header. Both desktop platforms share this component. Browser fixtures exercise both path formats, without establishing native macOS installer acceptance.
