# Generated media gallery

Completed images and videos from the same response turn share one gallery with a primary preview, horizontal thumbnails, previous/next buttons and a position indicator. Single outputs retain direct display. Active jobs use compact progress; individual errors remain in their own tool records. Separate conversation turns remain separate.

Choose thumbnails or use the arrow buttons; touchpads and touchscreens can scroll the thumbnail strip horizontally. There is no automatic rotation. Existing expand, save-as, external-open and side-panel actions apply to the selected item. Appending outputs preserves selection. Explicit receipt paths are no longer truncated by the former 8/12-item display limits; prose-derived file candidates remain bounded.

Only the selected video player is mounted. Other videos use numbered film icons without creating additional players or metadata requests. Switching stops the old player; the new video does not autoplay and preloads metadata only. Image thumbnails load lazily. Bounded preview height prevents the conversation from growing with every output.

This is a presentation change using existing verified files and tool receipts. Generation, permissions, persistence and Harness execution remain unchanged. Interaction follows user control, named buttons and position feedback from the [W3C Carousel Tutorial](https://www.w3.org/WAI/tutorials/carousels/), using existing React, CSS and media components without new dependencies or copied third-party implementations. Artwork quality and generation latency are outside this layout guarantee.
