## 已合入内容

- 长对话按窗口挂载历史节点，兼顾搜索、滚动与选区；媒体轮询和权限检查减少整段历史复制，运行中的会话支持导出已有内容。
- 活跃任务支持刷新 MCP 和技能能力；增加语义代码查询、版本化文档查询、媒体检查及网页质量检查入口，保留各能力的配置与依赖要求。
- 调整新聊天创建期间的消息与草稿状态、工具箱分组、历史筛选及工作区浏览器交互。
- 补齐新聊天提示的多语言文案，清理已移除界面的旧翻译；同步模型设置接口和上下文压缩触发线的浏览器测试。

实现与依赖详见 [Harness 说明](../runtime/harness/README.zh-CN.md)、[浏览器控制](browser-control.zh-CN.md)及[安全说明](../SECURITY.md)。
