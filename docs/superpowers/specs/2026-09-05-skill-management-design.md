# 技能管理與工具箱本地化設計

日期：2026-09-05。狀態：書面規格已核准，使用者已授權開發、測試與驗收。預設版本：繁體中文。

[简体中文](2026-09-05-skill-management-design.zh-CN.md) · [English](2026-09-05-skill-management-design.en.md)

## 目標與已確認問題

使用者可以透過介面或對話新增、下載、查詢、編輯、刪除技能；工具箱與技能頁遵循目前語言。刪除由 AI 發起時，仍由使用者確認具體目標。

目前 ToolboxView 直接呈現名稱、描述，沒有復用 SkillsView 與 ExtensionList 的內建項目翻譯。測試技能 acceptance-briefing 的原始描述也是英文。sources.rs 已有部分檔案型 CRUD，但不代表介面、下載與 AI 管理流程已完成；現有技能刪除直接移除目錄，不能冒充可恢復刪除。

## 方案選擇與產品比較

- 採用：介面與 AI 共用 Rust 管理服務，經現有 ACP 邊界暴露能力，保留既有技能目錄與探索規則。
- 不採用僅補介面：無法滿足對話代辦；不採用 AI 任意操作檔案：無法統一權限、衝突檢查與刷新。
- 官方 Codex 文件公開了 SKILL.md、顯式／隱式調用、使用者／專案範圍、独立展示元資料與安裝後探索。採用這些公開概念，不推斷其內部實作，不複製其儲存系統，也不在本次建造插件市場。
- 來源：[OpenAI Build skills](https://learn.chatgpt.com/docs/build-skills)，2026-09-05 查閱；此比較以公開文件為據，不聲稱已實測 Codex 的全部管理功能。

## 使用者流程

1. 技能頁提供搜尋、來源／範圍篩選、詳細資料，以及「新增」「匯入」「從連結下載」。工具箱技能卡可進入同一個詳細資料與管理介面。
2. 新增編輯器包含穩定識別碼、原始描述、技能正文、展示名稱／說明與專案／全域範圍。儲存前驗證 frontmatter；編輯保留未知欄位及附屬資源，不默默重命名識別碼。
3. 本地匯入支援 SKILL.md 與技能資料夾，保留 references、assets、scripts 等資源。內建或唯讀來源禁止直接修改／刪除，提供複製為可編輯技能。
4. 第一版遠端下載支援 GitHub 技能目錄連結與 HTTPS SKILL.md 直連。GitHub 來源解析為固定提交並記錄來源；直連明確提示只下載單檔。其他格式清楚報不支援，不偷偷執行套件管理器。需要登入的來源交由使用者處理，不搜尋憑證。
5. 安裝前呈現來源、目標範圍、檔案清單與名稱衝突。預設不覆蓋，允許取消或換名；覆蓋必須顯示差異並確認。下載到暫存位置，驗證成功後才發布，失敗不破壞原技能。
6. 刪除確認顯示名稱、來源、範圍及確切目標。移至應用管理的回收區，提供恢復；恢復衝突不覆蓋新內容。本次不提供永久清空，也不修改無關刪除 API 的語義。
7. 對話支援「幫我下載這個技能」「修改這個技能」「刪除這個技能」。AI 與介面使用相同服務；覆蓋／刪除須取得與具體預覽綁定的使用者確認，不能以模型自行產生的 confirmed 值取代授權。取消不產生異動。
8. 完成異動後刷新頁面與能力探索，下一次對話請求使用新狀態；進行中的回合不被靜默更換技能內容。刪除後不能再新載入該技能，恢復後重新可用。

## 語言與安全邊界

- 自有介面、狀態、操作提示與內建技能／工具的展示文案覆蓋繁體、簡體、英文，切換語言即更新；其他既有語言沿用明確的英文 fallback。
- 第三方識別碼、品牌、協議名不強制翻譯。展示名稱／說明可以本地化，詳情可看原文；不為了中文介面改写執行指令或隱式上傳技能內容。缺少譯文時標示原文語言並允許編輯展示文案，不聲稱所有第三方內容已翻譯。
- 以解析後的來源路徑和範圍識別目標，同名技能不得誤刪。寫入前重新檢查版本／內容指紋與授權範圍；變更過的目標要求重新預覽。
- 下載內容視為不可信資料：拒絕越界路徑、符號連結逃逸與無效技能格式；採用明確大小、檔案數和逾時上限；HTTPS 下載及每次重新導向拒絕本機／私有網路目標。安裝不執行下載的腳本。

## 模組與資料契約

- Rust 服務負責來源識別、列舉／讀取、預覽、套用、回收與恢復，復用現有 sources 與技能探索程式碼。ACP 與 AI 工具只做授權、型別轉接與結果傳送，不各自維護另一套技能庫。
- 讀取結果包含穩定來源參照、範圍、唯讀狀態、內容版本、原始元資料及展示元資料。變更預览返回目標、衝突、差異及受限操作憑據；套用時校驗憑據、版本和使用者確認事件。
- 操作成功返回實際目標與更新版本；刪除額外返回恢復參照。錯誤以現有 ACP 錯誤機制傳送穩定分類，例如無效輸入、唯讀、衝突、未授權、下載失敗，介面據此翻譯，技術詳情不洩漏憑證。
- 優先使用現有型別；必要契約變更採增量擴充並重新生成 ACP SDK，不引入舊 OpenAPI 客戶端。新功能預設不擴大 AI 的檔案權限或唯讀對話權限。

## 分階段驗收

1. 本地化：先增加回歸測試，再修復工具箱映射，驗證三語、原始識別碼不變及語言切換。
2. 本地管理：測試新增、匯入、查詢、編輯、同名衝突、唯讀、取消、越界、版本衝突、回收與恢復；重載後檔案及列表一致。
3. 遠端安裝：測試有效來源、附屬資源、大小上限、網路失敗、惡意路徑、重新導向、部分失敗與覆蓋回滾；完成一次真實下載及對話調用。
4. AI 代辦：測試工具註冊／路由、授權等待與取消、偽造確認被拒、目標變更後重新確認；以自然語言完成安裝、修改、刪除及恢復並核對工具記錄。
5. 完整驗收：跑受影響的 Rust／桌面完整測試、typecheck、lint、format、build，更新並執行 goose-self-test.yaml；从變更後源碼啟動 Electron，用真實滑鼠鍵盤操作，檢查刷新、重啟、檔案、對話與日誌。

每階段新增回歸未解決前不進入下一階段。記錄命令、cwd、退出碼、通過／失敗／跳過數與證據。登入、下載權限或桌面控制不可用屬驗收阻塞，不冒充產品測試通過。只使用隔離測試資料，不改既有 MCP 或使用者技能，不建立分支、不自動提交或推送。

## 展示元資料契約澄清（2026-09-05）

官方將展示名稱／說明放在可選的 `agents/openai.yaml.interface`；本機內建 skill-creator 檔案亦可觀察到此格式。[官方說明](https://learn.chatgpt.com/docs/build-skills)

本產品採用展示與執行識別分離，但不複製另一套儲存：沿用 `SKILL.md` 的 `metadata.codebuddy.display`，內容為 locale 到 `{name, description}` 的映射。這是 CodeBuddy 約定，不是 OpenAI 標準。ACP 提供型別化展示資料及完整原始元資料；只有明確提交的展示欄位才合併至對應節點。保留未知同級欄位、其他語言、原始正文及附屬檔案；節點型別衝突明確報錯。不更改穩定 `name`。缺少目前語言展示值時回退原文，不聲稱已翻譯。
