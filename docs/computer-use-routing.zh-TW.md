缺少可用圖片模型或輔助視覺時，Harness 在下一步前顯示錯誤並停止，保留原始動作回執而不重播。技能說明禁止用新增視窗快捷鍵代替啟用，也不以空輸入框判定傳送成功。輸入框移除拼圖圖示及擴充數量，工具箱與斜線選單仍可使用。

Windows 視覺與 ACP 回歸 8 項通過；Mac 原生、Harness、打包及安裝煙霧檢查通過。Mac ACP 首次受 SSH 鑰匙圈環境限制，改由已登入應用程式的子程序執行後通過。真實模型傳送訊息留待使用者驗收。

操作指引：載入技能、發現工具、列舉真實視窗、觀察、操作並驗證。視窗清單不是已安裝程式清單。焦點、過期觀察或使用者接管錯誤先重新觀察，持續失敗時回報，不用 AppleScript、SendKeys 或其他盲操作腳本繞過。單純啟動程式命令可以使用，但啟動成功不代表視窗就緒。傳送前核對對象與內容，傳送後檢查畫面；退出碼 0 或空輸出不是完成證據。這是模型操作指引，沒有新增關鍵字強制路由或第二套執行器。
